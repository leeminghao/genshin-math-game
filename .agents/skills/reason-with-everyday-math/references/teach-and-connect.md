## 讲解节奏

使用“具体—抽象—形式—检验—迁移”五拍：

1. **具体**：从用户熟悉的真实场景或小数字开始。
2. **抽象**：指出哪些细节可暂时忽略，哪些关系必须保留。
3. **形式**：再引入名称、符号、公式或证明步骤。
4. **检验**：用边界、反例、单位或另一种解法检查。
5. **迁移**：换一个领域展示同一结构，帮助用户真正掌握。

允许用户暂时跳过技术细节；把困惑视为理解过程的一部分。先讲广阔图景和概念联系，再按用户需要增加公式深度。

## 书中类比库

按目的选择类比，不要机械复述故事：

- **食谱与抽象**：蛋黄酱和荷兰酱共享过程，只替换油脂；用来说明一个结构可生成多个实例。
- **派与推广**：保留共同蓝图并替换馅料；用来说明放宽条件和参数化。
- **杂乱厨房与抽象**：收起当前不需要的东西；提醒不要丢掉会改变结果的条件。
- **地图与模型**：地图舍弃真实世界大量细节才变得有用；比例尺和用途决定保留什么。
- **路标与符号**：符号不像现实对象，却能压缩信息并跨越语言。
- **乐高与公理**：先规定积木和连接规则，再构造复杂结构。
- **三脚凳与证明层次**：从经验说法、机制解释逐步走到空间几何原理。
- **蛋糕糖霜与比例**：尺寸变化涉及顶部与侧面面积，不能只按直径简单同比例放大。
- **钟表算术**：在特定规则下 `10+4=2`；用来说明“对错”依赖定义和情境。
- **等边三角形与群**：把旋转、翻转视为可组合操作；用来说明对称和抽象结构。
- **甜甜圈与咖啡杯**：忽略长度角度、只保留连续形变关系；用来说明何谓“相同”。

先解释类比保留了什么，再解释它在哪些地方会失效。

## 概念讲解路线

### 数与运算

从一一对应、计数需要、位值和不同进制讲起，再进入负数、分数、无理数、质数。把数字说明为对“多少”的抽象，不把符号本身当数量。

### 代数

从把邮票、年龄或配料换成未知量开始。强调字母代表可变对象，等式代表平衡关系，变形必须保持关系。

### 几何与三角

从测地、建筑、透视、图形面积和不可直接测量的高度开始。先画图和找不变量，再给定理与公式。

### 概率与统计

从长期频率、扑克牌、筛查、彩票或平均工资开始。先用自然频数与分布，再引入条件概率、期望值、显著性和回归。

### 微积分

从纸盒最大体积、曲线局部斜率、连续累积和变化率开始。把导数解释为局部变化，把积分解释为许多微小贡献的总和。

### 无穷

区分“非常大”“没有终点”“趋近极限”和不同大小的无限集合。使用数列或一一对应，不依靠玄妙措辞。

### 证明

先问“为什么”，区分例证、解释和证明。展示假设、规则、每一步及结论；再用反例、归纳或反证深化。

### 抽象、结构与范畴视角

依次问：

1. 当前情境中什么性质重要？
2. 对象之间有什么关系或过程？
3. 哪些操作可以组合？
4. 哪些特征在变换后保持不变？
5. 何种意义下两个对象算“相同”？
6. 是否存在由关系而非内部材料刻画的“最自然”对象？

只在用户需要时使用“群”“范畴”“泛性质”等术语。

## 生活领域连接

| 领域 | 可连接的数学 | 适合的问题 |
|---|---|---|
| 烹饪 | 比例、面积体积、温度时间、算法 | 改配方、换模具、安排步骤 |
| 音乐 | 比率、周期、波、对称 | 音程为何和谐、节奏如何重复 |
| 运动 | 测量、平均、概率、优化 | 如何比较表现、选择策略 |
| 金钱 | 百分数、复利、期望值、效用 | 债务增长、投资骗局、风险选择 |
| 游戏与博彩 | 组合、概率、期望值 | 规则是否公平、庄家优势 |
| 时间管理 | 排序、调度、边际收益、停止策略 | 先做什么、何时停止搜索 |
| 关系与社交 | 图、网络、匹配、选择 | 朋友链、连接方式、候选筛选 |
| 健康 | 比率、条件概率、模型 | 如何理解筛查与风险表达 |
| 传播 | 指数、网络、阈值 | 信息或疾病为何先慢后快 |
| 建筑与手工艺 | 几何、对称、重复图案 | 结构如何兼顾功能与美感 |

不要把生活问题强行简化成唯一指标。涉及人的价值时，保留定性因素。

## 历史、艺术与文化

### 讲数学史

- 以“现实需要或思想问题—数学方法—传播与改变—后续影响”为主线。
- 连接埃及和巴比伦的计量、希腊的证明、中国的算法与历法、印度的数字、波斯与天文学、文艺复兴透视、微积分、现代代数几何与抽象化。
- 把数学呈现为多人、多地、长期发展的文明活动，不写成孤立天才突然创造一切。
- 需要人物故事时，聚焦其问题、方法和历史环境，而非只列生平。

### 看艺术与建筑

- 检查透视中的消失点、视平线和投影。
- 检查比例、正多面体、对称、变形和空间组织。
- 用几何视角补充艺术史或叙事视角，不宣称它是唯一解释。
- 观察时间、空间和光如何通过数学结构进入作品。

### 看民族数学

- 从计数、测量、辨向、设计、游戏、亲属关系、交易和建造中识别数学。
- 尊重不同文化的进制、算盘或结绳记录、图案、编织、折纸和本土算法。
- 说明这些实践依赖当地需求与经验，不把西方学术数学当成唯一合法形式。
- 先描述实践本身，再抽象出逻辑、几何、概率或算法结构。

## 课程与活动设计

设计一个活动时包含：

1. **生活钩子**：提出能猜、量、画、折、排或模拟的问题。
2. **可操作材料**：使用硬币、纸、绳、卡片、配方、地图或简单数据。
3. **核心概念**：每次只承载一个主要数学结构。
4. **预测**：让学习者先给直觉答案。
5. **实验或推理**：记录过程，不只公布答案。
6. **抽象命名**：在体验之后引入术语和符号。
7. **反例与边界**：改变一个条件，观察结论何时失效。
8. **迁移问题**：把同一结构放到另一个生活领域。

避免只追求“魔术效果”。揭示现象背后的规则、证明或模型局限，才完成数学学习。
