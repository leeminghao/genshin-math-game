## 选择任务路径

先判断用户真正需要哪一种结果：

1. **求值或估算**：找数量、比例、时间、面积、概率或人数。
2. **比较或决策**：比较方案、成本、收益、风险、公平性或等待策略。
3. **核查说法**：判断数字是否支持标题、广告、诊断、判决或预测。
4. **解释概念**：让用户形成直觉、理解定义、公式、证明或概念间联系。
5. **探索联系**：从艺术、文化、历史或生活实践中识别数学结构。

若一个请求同时包含多条路径，先完成决定性最强的一条，再补充其他路径。

## 七步建模

### 1. 定义问题

- 把宽泛问题改写成一个可回答的问题。
- 区分“发生了什么”“为什么发生”“接下来会怎样”“应该怎么选”。
- 明确判断标准。例如“最好”可能指最便宜、最快、风险最低或效用最高。

### 2. 确定对象与量

- 给每个量写明含义、单位、时间范围和适用人群。
- 分开总量、每单位量、变化量、变化率和比例。
- 标出输入、输出、可控变量、不可控变量和约束。

### 3. 抽象但不过度简化

- 去掉不会影响答案的故事细节。
- 保留容量、离散性、上限、下限、顺序、网络关系和现实后果。
- 根据情境处理同一个数值。例如 `100/15≈6.7`：载完100人需要向上取整为7辆车；不超过100克时只能向下取整为6块15克巧克力。
- 把抽象后的问题重新翻译回原情境，确认没有把“婴儿和洗澡水一起倒掉”。

### 4. 写出假设

使用“如果……那么……”表达假设与结论，例如：

- 如果增长率在每期保持不变，那么使用指数模型。
- 如果第二次抽样能代表总体且标记不丢失，那么可用标记重捕估算总体。
- 如果两个事件独立，那么才可把它们的概率相乘。
- 如果样本只包含幸存者，那么不能把它当作原总体的随机样本。

把定义、观测和假设分开。不要把假设藏在公式里。

### 5. 选择并执行模型

- 从最简单的可用模型开始。
- 先用小数目、自然频数、草图或量纲建立直觉。
- 再给公式、代入、结果与单位。
- 若两个模型都合理，给出情景范围，并指出决定差异的假设。

### 6. 检验结果

- 检查单位是否一致、结果是否可能、数量级是否合理。
- 代入简单值、零值、极大值和边界值。
- 反向计算，确认结果能复原输入。
- 寻找反例；一个反例足以推翻全称说法。
- 改变关键假设或输入，观察答案是否剧烈变化。

### 7. 回到现实

- 用原问题的语言回答，不停在公式上。
- 说明答案对哪些条件成立、对哪些条件不成立。
- 区分数学能回答的事实问题与需要价值取舍的问题。
- 若行为结果本身不确定，给出概率或条件性结论，而不是装作确定。

## 选择数学镜头

| 现象线索 | 首选镜头 | 首要追问 |
|---|---|---|
| 每单位、配方、汇率、速度 | 比率、比例、单位换算 | 分子分母和单位是什么？ |
| 每期增加固定数量 | 线性模型 | 适用范围会不会结束？ |
| 每期按当前量的固定比例变化 | 指数模型 | 资源或容量何时打破增长？ |
| 最多、最少、最佳尺寸或时间 | 代数、几何、优化 | 目标函数和约束是什么？ |
| 路线、配对、顺序、选择数量 | 组合、图、算法 | 是否计顺序？能否重复？ |
| 测试、风险、证据、博彩 | 条件概率、贝叶斯、期望值 | 基准率与条件方向是什么？ |
| 平均、趋势、差异、预测 | 统计、回归 | 分布、样本和不确定性是什么？ |
| 周期、星期、校验码 | 模运算 | 余数循环以几为模？ |
| 形状、视角、空间、测量 | 几何、三角、对称 | 哪些量在变换下保持不变？ |
| 连续变化、瞬时变化、累积 | 微积分 | 研究斜率还是总量？ |
| 规则、相似、结构、证明 | 公理、关系、推广 | 哪些规则固定，哪些细节可替换？ |

## 压力测试

至少选择与风险相称的三项检查：

- **量纲检查**：人数不能与百分比直接相加，速度必须含距离和时间单位。
- **边界检查**：概率应在0与1之间，人数不能为负，容量不能无限增长。
- **数量级检查**：先用近似值估算，再看精算结果是否同一量级。
- **样本检查**：寻找未被观察、退出、失败或无法返航的对象。
- **方向检查**：区分 `P(证据|假设)` 与 `P(假设|证据)`。
- **独立性检查**：共同原因、重复测量或信息重叠会破坏独立性。
- **分布检查**：比较均值、中位数、范围和异常值。
- **模型检查**：比较线性与指数、局部与长期、相关与因果。
- **敏感性检查**：让关键输入上下浮动，报告结论是否改变。
- **价值检查**：辨认公式中被量化或被忽略的偏好、公平与效用。

## 输出模板

### 现实求解

1. **结论**：直接回答，并带单位或范围。
2. **模型**：列出变量、关键假设和选择理由。
3. **推理**：展示足够复核的计算。
4. **检查**：给出边界、敏感性或替代情景。
5. **局限**：指出现实中未被模型覆盖的部分。

### 数据不足

1. 说明当前能确定什么。
2. 给出符号关系或上下界。
3. 只请求会实质改变答案的最小数据。

### 概念解释

1. 用生活例子制造直觉。
2. 抽掉无关细节，点出共同结构。
3. 给定义或公式。
4. 用反例或边界说明适用范围。
5. 换一个领域让用户迁移理解。
