## 七层审查

### 1. 还原原始说法

- 写出主语、指标、总体、时间、比较对象和结论强度。
- 把“更高”“翻倍”“准确”“有效”“显著”等词换成可量化问题。
- 找到分子、分母和基准；没有基准的百分比通常无法判断意义。

### 2. 追问数据如何出现

- 谁被纳入、谁没有机会出现、谁退出或失败？
- 样本是否代表要推断的总体？
- 观察方式会不会改变结果？
- 是否只展示幸存、成功、发表或有利的案例？

### 3. 检查条件概率

- 写出条件在竖线哪一侧。
- 加入疾病流行率、犯罪率或其他基准率。
- 用10,000人的自然频数表展开真阳性、假阳性、真阴性、假阴性。
- 只有在错误来源独立时才相乘；共享设备、证人、样本或模型会产生相关错误。

### 4. 检查统计摘要

- 比较均值、中位数、众数、范围和分布。
- 同时给绝对数、相对数和样本量。
- 检查图轴、面积、饼图、截断范围和视觉比例是否夸大差异。
- 检查“显著”是统计意义还是日常意义。

### 5. 检查模型

- 识别线性、指数、回归、网络或优化假设。
- 问模型在观察范围外是否仍成立。
- 查找容量、资源、阈值、反馈、行为变化和不可逆约束。
- 对预测给情景或分布，不只给一条精确轨迹。

### 6. 检查因果

- 按顺序检查：相关、时间先后、替代解释、共同原因、反向因果、选择机制。
- 区分个体结论与群体结论。
- 警惕干预发生在极端值之后造成的回归均值错觉。
- 若数据只能支持关联，就把措辞降为“相关”“伴随”或“可预测”。

### 7. 检查结论与价值

- 判断计算回答的是事实问题，还是偷偷替用户决定了公平、生命质量或风险偏好。
- 区分期望收益、成功概率、最坏损失和个人效用。
- 报告误差、不确定性和结果对关键假设的敏感程度。
- 删除超过数据质量的小数位。

## 常见误区

| 误区 | 错在哪里 | 修正方式 |
|---|---|---|
| 幸存者偏差 | 只看到返回或存活者 | 寻找缺失对象和选择机制 |
| 检察官谬误 | 把证据条件下的概率倒置 | 写清两个条件概率并加入基准率 |
| 生态谬误 | 把群体关系套到个人 | 分层或取得个体数据 |
| 基准率忽视 | 高准确度不等于阳性后高概率 | 使用自然频数表 |
| 独立性幻觉 | 重复证据可能共享错误来源 | 画出共同原因 |
| 相对风险夸大 | 只报百分比变化 | 同时报原始风险和绝对变化 |
| 线性外推 | 局部直线被延伸到长期 | 检查边界、饱和和非线性 |
| 指数直觉不足 | 低估连续按比例变化 | 逐期列值并检查资源上限 |
| 回归均值 | 极端后自然回落被归功于措施 | 使用对照或多次测量 |
| 多重比较 | 尝试越多越容易偶然“命中” | 报告检验总数和预先假设 |
| 相关即因果 | 方向和共同原因未识别 | 列出因果候选并降级结论 |
| 虚假精确 | 小数位超过数据能力 | 给合理范围和有效位数 |
| 期望值误读 | 平均结果被当作个人保证 | 展示完整结果分布和效用 |

## 书中典型案例

### 返航飞机

返航飞机机身弹孔多、引擎弹孔少，不代表引擎较少中弹；引擎中弹的飞机更可能没有返航。使用该案例检查样本是否因结果而被筛选。

### 医学筛查

书中使用10,000名50岁以上女性说明基准率：若患病率为0.4%，灵敏度和特异度均约90%，则约40人患病，其中36人真阳性；9,960名未患病者中约996人假阳性。阳性者中真正患病者约为 `36/(36+996)=3.49%`。使用该结构讲条件概率，不把书中数值用于当前诊断。

### “平均”工资

少数高薪者可把均值拉高，使它无法代表多数人的典型工资。比较工作机会时，同时看中位数、分布和职位，而不是只看均值。

### 金字塔招募

每人继续招募固定人数会形成指数增长；早期成功案例不能消除参与者最终超过可用人口的结构性失败。逐层列人数并检查资源上限。

### 显著结果与大量尝试

当预测、选股或文本搜索尝试足够多时，偶然命中并不罕见。必须把成功案例放回全部尝试中评价。

### 回归均值

极端成绩、身高或健康读数之后通常更接近总体平均。若干预恰好在极端点发生，不能仅凭随后改善认定其有效。

## 决策框架

### 列出决策表

为每个方案列出：

- 可能结果；
- 每个结果的概率或可比较的情景；
- 收益、成本和不可逆后果；
- 最坏结果是否可承受；
- 哪个输入最可能改变选择。

### 区分三种“最好”

1. **期望值最高**：长期重复下平均收益高。
2. **成功概率最高**：最常赢，但收益规模可能小。
3. **期望效用最高**：把个人价值、边际效用和风险承受纳入。

不要在三者之间偷换。

### 处理不可约不确定性

- 给出概率、区间或多个情景。
- 说明哪些不确定性来自数据，哪些来自模型，哪些来自未来行为。
- 判断收集新信息的价值；若信息不会改变选择，就停止追求虚假精确。
- 做一次反向论证：认真尝试证明首选方案是错的，并记录最强反例。

### 呈现决定

使用以下格式：

1. 在当前假设下，方案A更符合目标X。
2. 决定主要由参数Y和偏好Z驱动。
3. 当Y跨过某阈值或偏好改为Z2时，方案B会更合适。
4. 数学没有决定的价值部分是……

## 高风险场景

- **医疗**：解释灵敏度、特异度、基准率、假阳性和假阴性；不要诊断，不把书中旧数据用于个人。
- **法律**：解释证据强度、条件概率、独立性和群体到个人的跳跃；不要判断有罪或提供法律意见。
- **金融**：解释复利、指数风险、期望值和效用；不要承诺收益，也不要用书中案例替代当前产品数据。
- **公共政策**：揭示模型、样本、权重和价值取舍；不要把公式包装成没有伦理选择的“客观答案”。
