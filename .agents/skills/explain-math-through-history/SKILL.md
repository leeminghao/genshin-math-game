# 用历史讲懂数学

## 目标

把数学概念还原为长期积累的思想变化：人们先遇到什么问题，旧表示哪里失效，哪个新对象或规则由此出现，如何经受证明与争论，又怎样改变后来的数学和物理。让故事承载技术解释，让证据限制故事强度。

## 守住唯一来源

- 只使用本技能参考资料中的历史内容；这些资料全部提炼自 `books/尖叫的数学.epub`。
- 处理用户提供的补充材料时，明确标注“用户提供”，不要把它混入本书依据。
- 遇到六条主题主线之外的历史问题时，说明来源未覆盖；可以给出叙事框架，但不要补造人物、年代或发现史。
- 需要核对章节和来源范围时，读取 [references/source-map.md](references/source-map.md)。
- 只做概括和重组，不输出大段原文。

## 执行历史化解释

1. **界定请求。** 明确概念、受众、篇幅和产物；确认它是否属于本书覆盖范围。
2. **提出核心问题。** 先用一句现代语言说明概念，再把它改写成当时人可能面对的实际困难、悖论或证明障碍。
3. **选择入口场景。** 从实物实践、语言矛盾、未来应用、人际冲突或著名失败中选一个；场景必须服务于概念转折。
4. **拆开概念层级。** 按需要区分：实物或操作 → 记号或表示 → 抽象对象 → 运算规则 → 证明或公理 → 模型或应用。不要把记号出现直接说成概念已经成熟。
5. **建立因果时间线。** 依次呈现早期线索、跨文化积累、决定性转变、阻力或错误、形式化和后续影响。把“关键时刻”写成累积链的转折点，而非凭空闪现的神迹。
6. **插入技术支点。** 至少用一个最小计算、图形操作、反证思路或公理变化说明为什么新思想有效；不让人物轶事替代数学。
7. **标注证据等级。** 把可确认叙述与书中转述的传说、推测、争议和后世解释分开。证据越弱，措辞越保守。
8. **说明真正改变了什么。** 指出新思想改变的是对象、表示、允许的操作、证明标准，还是数学与现实的关系。
9. **收束而不封死。** 总结遗产、仍有争议之处以及一个能让受众重新观察该概念的问题。

## 使用“概念阶梯”检查叙述

对每一层分别问：

- **实践层**：最初需要计数、测量、求解或描述什么？
- **表示层**：使用了刻痕、位置、符号、图形或方程中的哪一种？
- **对象层**：什么时候开始把表示背后的共同结构当作数学对象？
- **规则层**：哪些运算先能做，却还缺少解释或合法性？
- **证明层**：经验近似如何变成一般论证、反证、公理系统或不可能性证明？
- **应用层**：后来如何回到自然科学、技术、艺术或日常理解？

不是每个主题都需要六层齐全，但不得跳过恰好构成用户困惑的那一层。

## 组织默认回答

按任务裁剪以下结构：

1. **今天的概念**：一句话定义讨论对象。
2. **最初的难题**：给出历史入口与旧方法的限制。
3. **演化链**：列出三至六个真正改变概念的节点。
4. **数学转轴**：用最小技术例子讲清关键变化。
5. **争议与证据**：区分可确认、推测、传说和命名误导。
6. **后来为何重要**：说明形式化或应用结果。
7. **一句话带走**：概括人类思维跨过了哪一道门槛。

## 质量准则

- 不写人物和年代的流水账；每个人物必须推动一个明确的概念变化。
- 不制造“孤独天才一次发明一切”的神话；优先展示多人、多地和多世纪积累。
- 不因定理以某人命名就断言由他最先发现；分别讨论早期实例、证明、系统化和传播。
- 不把近似数值、精确表达和尺规可作混为一谈；不把符号、对象和运算规则混为一谈。
- 不把失败研究当作空白。说明它澄清了哪些限制、创造了哪些方法或导向了哪种不可能性证明。
- 不以戏剧性牺牲准确度。来源无法确定时，直说“本书无法确定”或“书中将其作为一种可能重建”。
- 不把数学内部的一致性直接等同于物理现实；区分可构造的数学世界与需要经验判断的空间模型。
