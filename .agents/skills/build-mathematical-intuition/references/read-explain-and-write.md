# 阅读、讨论、书写与讲解

## 用途

处理“教材读不进去”“证明跳步”“我会做但讲不清”以及教学设计问题。把阅读和写作改造成主动重建理解的过程。

来源定位：第5–8、12–14、20章及后记，PDF 第34–77、115–153、218–240页。

## 阅读数学材料

不要默认从第一页线性读到最后一页。把材料当作解决当前问题的手册：

1. 先写下自己真正想知道的问题。
2. 跳到最可能回答它的图、例子、命题或结论。
3. 只在一个术语确实阻塞理解时回找定义。
4. 读一小段后合上材料，凭自己的图像重述。
5. 标出作者省略的心理动作，而不只是陌生符号。
6. 预测下一步，再与原文比较。
7. 找到足够信息后，离开原文亲自操作。

形式文本擅长精确保存结果，却常压缩了发现与理解所需的动作。阅读目标不是服从书的顺序，而是重建这些动作。

## 拆解一个证明跳步

对相邻两行逐项提问：

- 哪个对象发生了变化？
- 哪些量保持不变？
- 使用了哪条定义或已知结论？
- 作者默认读者能完成什么动作？
- 能否画出变化前后？
- 能否用不含术语的一句话描述？

若一步看起来像诀窍，插入足够多的中间状态，直到变换可以连续追踪。

## 在思考过程中书写

不要等理解完成才写。循环执行：

1. 写下模糊感觉或图像片段；
2. 尝试用最简单的句子固定它；
3. 用定义检查句子是否过宽、过窄或歧义；
4. 根据冲突回到图像；
5. 重写句子并保留版本差异。

书写不是把完成的想法抄下来，而是迫使短暂、含混的表征变得稳定和精确。保留错误版本，因为修订轨迹揭示了理解怎样变化。

## 进行面对面式对话

即使在文字交互中，也模拟可打断的面对面对话：

- 允许随时说“从头再讲，我没懂”；
- 鼓励最基础、重复或看似愚蠢的问题；
- 每次只推进一个动作，并检查对方脑中出现了什么；
- 先问对象的用途和整体意思，再补装配细节；
- 请理解者分享自己的私人图像、手势和近似说法，同时标明其边界。

这种“装傻”姿态不是表演无知，而是撤掉身份压力，让被正式文本隐藏的直觉层浮现。

## 设计讲解

按最低认知负担排序：

1. **动机**：为什么要构造这个对象或解决这个问题？
2. **熟悉入口**：听众已经能感知什么？
3. **一个动作**：让听众亲自画、摆、比较或预测。
4. **核心图像**：给出能承载关系的简单表征。
5. **形式名字**：在对象出现后再引入术语和符号。
6. **边界测试**：给出非例子、反例或容易误解处。
7. **严谨层**：说明定义和证明如何固定直觉。
8. **复述**：让听众用自己的话和图像重建。

不要只讲直觉，也不要只讲形式。缺少动机和图像的形式讲解会把动作藏起来；缺少定义和检验的直觉讲解没有支撑点。

## “向孩子解释”测试

用以下约束检查理解：

- 不依赖“显然”“容易看出”“套公式即可”；
- 每个术语都能指向一个对象、动作或关系；
- 听众可以在下一步发生前做出预测；
- 能诚实指出图像不精确的地方；
- 能回答“为什么不是另一个结果”；
- 能把形式结论放回最初问题。

如果讲不清，不要归咎于听众；把卡点作为自己的下一轮理解目标。

