# Chapter 11: 统一度量衡

## 核心观点

单位使数字接入现实。量纲分析可以检查公式是否有意义，统一度量衡让科学沟通和计算可复用。

## 操作步骤

1. 从面积、体积等公式检查单位匹配。
2. 区分有量纲量和无量纲常数。
3. 说明基本单位和导出单位的关系。
4. 介绍公制和 SI 单位的统一意义。
5. 用量纲分析发现明显公式错误。

## 典型工具

- 单位
- 量纲分析
- SI 基本单位
- 导出单位
- 无量纲常数

## 案例要点

- 正方形面积公式两边单位都应为平方米。
- π 是无量纲常数，不改变面积公式量纲。
- 秒、米、千克等单位定义体现测量标准化。
