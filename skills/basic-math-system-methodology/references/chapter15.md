# Chapter 15: 优化

## 核心观点

优化问题关心最大、最小或最合适。若现实约束能写成代数关系，就可通过图像或解析方法寻找最优解。

## 操作步骤

1. 明确要最大化或最小化的目标。
2. 写出现实约束条件。
3. 用变量表达目标量。
4. 将目标写成变量函数。
5. 通过图像、完全平方或其他方法寻找极值。

## 典型工具

- 目标函数
- 约束条件
- 最大值
- 最小值
- 二次方程
- 图形解

## 案例要点

- 用 100 码绳子围矩形土地，目标是面积最大。
- 将长表示为 `100 - 2w` 后，面积只依赖宽度。
- 优化章节把代数从求未知推进到求最佳。
