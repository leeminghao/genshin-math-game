# Chapter 23: 正态分布

## 核心观点

很多自然和社会数据呈钟形曲线，围绕平均数集中。标准差描述离中心多远，正态分布提供常见数据判断框架。

## 操作步骤

1. 收集同类测量数据。
2. 绘制频率分布，观察是否接近钟形。
3. 找到平均数作为中心。
4. 用标准差衡量偏离程度。
5. 使用 68-95-99.7 规则解释数据范围。

## 典型工具

- 正态分布
- 钟形曲线
- 平均数
- 标准差
- 西格玛
- 68-95-99.7 规则

## 案例要点

- 苹果重量、人体测量数据常可近似为正态分布。
- 5 西格玛表示极罕见偏离，用于科学发现置信判断。
- 正态分布支撑服装、家具、交通工具等尺寸设计。
