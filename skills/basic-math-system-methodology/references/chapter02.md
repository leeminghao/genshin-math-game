# Chapter 02: 康托尔计数法

## 核心观点

无穷不是单一概念。康托尔用集合、基数和一一对应说明：有些无穷可以计数，有些无穷无法按自然数顺序列完。

## 操作步骤

1. 从有限集合的元素个数引入基数。
2. 用自然数集合说明可数无穷。
3. 对比自然数、整数、平方数等集合的一一对应。
4. 引入区间内实数，说明不可数无穷。
5. 区分“无限多”和“同样多”的直觉冲突。

## 典型工具

- 集合
- 基数
- 一一对应
- 可数无穷
- 不可数无穷
- 伽利略悖论

## 案例要点

- 平方数似乎比自然数少，但可以与自然数建立一一对应。
- 自然数、整数都可数；0 到 1 之间的实数不可数。
- 本章用于打开数量规模的抽象理解，不是计算技巧章节。
