# Chapter 13: 比率

## 核心观点

比率表达多个量之间的相对份额。它与分数、除法有关，但不完全相同，尤其在配比和分配问题中更清晰。

## 操作步骤

1. 区分比率、分数和除法表达的不同语境。
2. 将两个或多个数量写成比。
3. 化简比率但保持相对关系。
4. 用总份数解决分配问题。
5. 用比例尺连接图上距离和实际距离。

## 典型工具

- 比率
- 分数
- 除法
- 化简
- 总份数
- 比例尺

## 案例要点

- 水和蒸粗麦粉的 `160:100` 可化简为 `8:5`。
- 比率中的某一份占总量时，分母应是总份数。
- 地图 `1:50000` 是图上距离与真实距离的比。
