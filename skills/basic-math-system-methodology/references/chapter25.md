# Chapter 25: 可能性

## 核心观点

概率用 0 到 1 的数表达事件发生的可能性。计算概率前必须明确结果、事件、假设和事件关系。

## 操作步骤

1. 明确实验或情境中的所有可能结果。
2. 定义要计算的事件。
3. 判断结果是否等可能。
4. 判断事件是否互斥、独立。
5. 用有利结果数除以总结果数，或用规则组合计算。

## 典型工具

- 结果
- 事件
- 概率
- 互斥事件
- 独立事件
- 等可能假设

## 案例要点

- 掷一个公平骰子有 6 种结果。
- 概率范围从 0 到 1，也可写成分数、小数或百分数。
- 本章强调概率计算依赖假设，而不是只套公式。
