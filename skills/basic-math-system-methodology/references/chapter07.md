# Chapter 07: 二进制数

## 核心观点

十进制不是唯一计数方式。二进制用 2 的乘方建立位值系统，是现代计算机数字表示的基础。

## 操作步骤

1. 回顾十进制位值基于 10 的乘方。
2. 将同样思想转移到 2 的乘方。
3. 用 0 和 1 表示每一位是否存在。
4. 解释电子电路为什么适合二元状态。
5. 连接二进制、布尔逻辑和计算机。

## 典型工具

- 二进制
- 位值
- 2 的乘方
- 0/1 状态
- 布尔逻辑

## 案例要点

- 计算机采用二进制，与电子电路的稳定状态有关。
- 《易经》、莱布尼茨、布尔、香农都构成二进制思想史线索。
- 本章把数的表示从人类习惯扩展到机器表示。
