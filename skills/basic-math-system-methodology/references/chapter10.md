# Chapter 10: 百分数

## 核心观点

百分数是分母为 100 的标准化分数，核心价值是便于比较。现代金融、税收、利率、通胀和折扣都依赖它。

## 操作步骤

1. 将百分数定义为“每一百中有多少”。
2. 将分数、小数和百分数互相转换。
3. 用乘法计算某个数的百分之几。
4. 比较不同百分比的大小和影响。
5. 警惕百分比变化的基准不同。

## 典型工具

- 百分数
- 百分比
- 分数转换
- 小数转换
- 利率、税率、增长率

## 案例要点

- 11.74% 和 11.8% 比两个复杂分数更容易比较。
- 计算税额时可用 `总额 × 税率`。
- 百分数章节承接分数，同时进入现实比较。
