# Chapter 19: 毕达哥拉斯定理

## 核心观点

毕达哥拉斯定理揭示直角三角形三边的平方关系。它的重要性不仅在公式，还在通过面积重排得到证明。

## 操作步骤

1. 识别直角三角形和斜边。
2. 将两条直角边记为 `a`、`b`，斜边记为 `h`。
3. 用四个相同三角形重排比较面积。
4. 推出 `h^2 = a^2 + b^2`。
5. 用公式计算未知边长。

## 典型工具

- 直角三角形
- 斜边
- 平方
- 面积重排
- 毕达哥拉斯三元组

## 案例要点

- 该定理在多种文化中早已使用，毕达哥拉斯传统重视证明。
- `3,4,5`、`7,24,25` 是典型整数三元组。
- 本章连接几何图形、代数方程和证明思想。
