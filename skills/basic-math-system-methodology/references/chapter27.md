# Chapter 27: 相对频率

## 核心观点

当理论概率无法直接列举时，可以用长期记录的相对频率估计可能性。样本越多，估计通常越稳定。

## 操作步骤

1. 明确要估计的事件。
2. 连续记录事件发生次数和总次数。
3. 用发生次数除以总次数得到相对频率。
4. 随着记录增加更新估计。
5. 区分相对频率、理论概率和赌徒谬论。

## 典型工具

- 相对频率
- 经验概率
- 长期记录
- 独立性
- 样本量
- 赌徒谬论

## 案例要点

- 记录喝咖啡天数可估计任意一天喝咖啡的概率。
- 保险公司会用历史频率估计风险。
- 连续 8 次硬币正面不代表下一次反面概率更高。
