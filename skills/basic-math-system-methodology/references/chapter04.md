# Chapter 04: 加法和乘法

## 核心观点

加法依赖位值系统，乘法是重复加法的压缩。理解展开式和进位，比只会竖式更重要。

## 操作步骤

1. 将多位数拆成个位、十位、百位等位值。
2. 用展开式表达数字。
3. 按相同位值进行加法。
4. 解释进位的本质是单位转换。
5. 将乘法理解为多个相同加数的快速写法。

## 典型工具

- 位值
- 展开式
- 进位
- 重复加法
- 乘法表

## 案例要点

- `1234 = 4 + 30 + 200 + 1000` 展示了位值结构。
- 竖式加法只是展开式计算的压缩记录。
- 乘法的意义不是符号规则，而是重复相加的结构化表达。
