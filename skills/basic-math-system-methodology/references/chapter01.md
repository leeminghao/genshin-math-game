# Chapter 01: 数的分类

## 核心观点

数学基础首先是数系分类。自然数、整数、有理数、无理数和实数不是并列名词，而是逐层扩展的数的“地图”。

## 操作步骤

1. 从日常数数进入自然数。
2. 加入 0 和负数，扩展到整数。
3. 用分数表达整数之间的份额，进入有理数。
4. 用无法写成分数的量引出无理数。
5. 将有理数和无理数共同放入实数体系。

## 典型工具

- 数轴
- 集合包含关系
- 自然数、整数、有理数、无理数、实数
- 例子与反例

## 案例要点

- 手机可以计算，但理解数的分类才能理解计算对象。
- 0 在古典直觉中不一定属于自然数，但在现代体系中常作为桥梁处理。
- 分清数系边界，是后续分数、小数、平方根、无穷的基础。
