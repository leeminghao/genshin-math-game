# Chapter 03: 算术方法

## 核心观点

算术不应只是机械步骤。符号、正负、运算指令和数值描述需要被理解，否则后续算法会失去基础。

## 操作步骤

1. 区分 `+`、`-` 作为运算符号和正负号的不同含义。
2. 解释运算步骤背后的数值变化。
3. 将计算过程与理解过程连接起来。
4. 用简单算例检查是否只是记住流程。
5. 为加减乘除的结构化解释做准备。

## 典型工具

- 加号、减号
- 正数、负数
- 运算过程
- 符号含义
- 算法理解

## 案例要点

- 本章强调“记住事实、算法和过程”不足以建立数学金字塔。
- `-` 既可能表示“减去”，也可能表示“负数”。
- 算术方法是后面所有数学表达的底层操作语言。
