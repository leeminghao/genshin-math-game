# 教学与表达格式

## 用途

把同一条概念史改写成不同长度、受众和目标的产物，同时保留技术解释与证据边界。

来源定位：全书的提问式讲述、文学入口、图形说明、历史转折与后记。

## 90秒概念故事

按五句组织：

1. 今天我们把什么视为理所当然？
2. 过去的哪个具体困难暴露了它并不当然？
3. 哪个新表示、对象或规则跨过了障碍？
4. 用一个计算或图形动作说明转折。
5. 它后来开启了什么，同时还有哪一点不能确定？

只保留一名核心人物或一个核心场景；其他贡献者概括为背景积累。

## 证据型时间线

每个节点包含四列：

| 时期 | 材料或人物 | 概念变化 | 证据状态 |
|---|---|---|---|
| 早期 | 实物、文本或实践 | 能做什么，还不能做什么 | 可确认/书中归属 |
| 过渡 | 多地线索或失败尝试 | 旧框架出现裂缝 | 争议/推测 |
| 转折 | 表示、规则、证明或公理改变 | 新对象成立 | 按来源标注 |
| 巩固 | 后续数学家与作品 | 系统化或不可能性证明 | 按来源标注 |
| 后世 | 科学、技术或艺术 | 新应用或新解释 | 后世应用 |

时间无法确定时使用世纪、时期或先后关系，不编造年份。

## 15分钟课堂导入

1. **2分钟：制造困惑。** 展示刻痕、空位、正方形对角线、圆、负数平方根或球面路线。
2. **3分钟：让学生先猜。** 询问旧方法哪里会失效。
3. **4分钟：完成技术动作。** 做一次位值比较、反证、夹逼、共轭运算或公设替换。
4. **3分钟：给出历史演化链。** 只讲与该动作直接相关的节点。
5. **2分钟：辨别证据。** 让学生区分文物、传说和可能重建。
6. **1分钟：回到今天。** 说明概念为何仍在现代数学或物理中工作。

不要先灌输完整年代清单；先让学生感到旧工具确实不够用。

## 人物或发现归属辟谣

使用“不是简单否定，而是重新拆分贡献”的结构：

```text
常见说法：
它为什么流行：
本书能确认的早期材料：
普遍证明或系统化来自哪里：
命名、传播与后世形象：
仍不能确定的部分：
```

例如，不把“毕达哥拉斯未必最先知道勾股关系”改写成“毕达哥拉斯毫无贡献”。区分关系实例、证明传统和学派系统化。

## 两个概念的比较稿

选用统一维度：

- 最初问题；
- 首个表示；
- 被排斥的原因；
- 获得运算合法性的方式；
- 证明标准；
- 后世应用；
- 史料不确定性。

适合比较零与虚数、无理数与超越数、欧氏与非欧几何、数值近似与精确构造。

## 科普文章

使用“未来结果 → 回到旧问题 → 连续失败 → 技术转轴 → 现代回响”的环形结构。第五章从量子力学回望复数、第六章从1919年日食回望第五公设，都是这种写法。

控制人物密度：每800字最多保留三至五个必须点名的人物；其余用“此前的数学家”“多个文明”或“后续研究者”概括。若用户需要详细史表，再展开完整节点。

## 自检问题

- 去掉人物姓名后，读者仍能说出概念怎样变化吗？
- 去掉公式后，文章是否还说明了旧方法为何失效？
- 保留公式时，是否解释了它在故事中的作用？
- 是否把文学场景明确当作文化表达，而不是史料？
- 是否至少指出一个不确定或有争议之处？
- 是否区分“后来有用”与“当初为了该用途而发明”？
