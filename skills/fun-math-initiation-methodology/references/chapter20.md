# Chapter 20: 音乐

## 核心观点

音乐用节奏、重复和结构增强记忆。数学启蒙可以借助音乐，但更重要的是让孩子看到声音中的模式。

## 操作步骤

1. 从歌词、节拍、儿歌、说唱、打击乐进入。
2. 让玩家感受重复、间隔、快慢和节奏单位。
3. 把声音结构表示成拍子、格子或序列。
4. 用节奏记忆数学规则或触发机关。
5. 迁移到记忆、机关时序、周期系统。

## 典型工具

- 节拍
- 重复
- 模式
- 比例
- 序列
- 周期

## 案例要点

- 学生能记歌词却记不住公式，说明节奏是强记忆载体。
- 游戏中可设计为：玩家按节奏修复机器，理解周期和倍数。
- 不要只把公式编成歌，要让节奏影响世界操作。
