# Chapter 25: 赌博

## 核心观点

赌博启蒙的重点不是鼓励冒险，而是让孩子理解“短期可能赢，长期看期望”。庄家优势是概率结构。

## 操作步骤

1. 从赌场、抽卡、轮盘、彩票、随机奖励进入。
2. 区分单次结果和长期平均。
3. 计算或模拟期望值。
4. 识别规则中谁占优势。
5. 迁移到抽卡、掉落、风险投资、资源赌局。

## 典型工具

- 概率
- 期望值
- 赔率
- 庄家优势
- 长期频率

## 案例要点

- 赌场“娱乐可接受，赢钱不可期待”适合做价值判断。
- 游戏中可设计为：玩家可以抽稀有材料，但长期成本可见。
- 避免做刺激赌博循环，重点是风险教育。
