# Chapter 15: 收藏

## 核心观点

收藏是分类、测量和数据结构的天然入口。孩子通过整理相似物品，理解属性、单位和类别。

## 操作步骤

1. 从邮票、硬币、石头、卡片等收藏对象进入。
2. 让玩家提出分类标准：颜色、大小、来源、时间、状态。
3. 比较不同分类方式带来的查找和使用效率。
4. 引入属性、标签和单位。
5. 迁移到仓库、合成、交易、图鉴、任务条件。

## 典型工具

- 分类
- 属性
- 标签
- 测量
- 单位
- 数据集

## 案例要点

- 邮票收藏展示同一对象可以按多个维度组织。
- 游戏中可设计为：未分类材料无法稳定合成，分类越清楚，配方越可靠。
- 关键是分类要有后果，不能只是整理界面。
