# Chapter 08: π 与圆

## 核心观点

π 的价值不是记忆小数，而是把圆、轮子、轨道、范围等曲线世界变成可度量对象。

## 操作步骤

1. 从绳子绕圆、轮子滚动、水池边界、披萨切分进入。
2. 对比直线长度和曲线长度的测量困难。
3. 建立半径、直径、圆周和面积之间的关系。
4. 使用近似理解现实测量。
5. 迁移到车轮、管道、喷灌范围、圆形建筑。

## 典型工具

- 半径
- 直径
- 圆周
- 面积
- π
- 近似
- 分割拼补

## 案例要点

- 绳子绕地球加长的反直觉问题适合制造惊奇。
- 游戏中可设计为：建造圆形水池或灌溉器，需要估计边界和覆盖面积。
- 不要让 π 只作为背诵对象，必须绑定建造需求。
