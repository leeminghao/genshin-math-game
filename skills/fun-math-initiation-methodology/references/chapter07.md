# Chapter 07: 几何学

## 核心观点

几何不是图形名称，而是空间中的边界、路径、面积、对称和结构关系。儿童应通过建造和移动理解几何。

## 操作步骤

1. 从画图、围栏、道路、地块、桥梁等空间需求进入。
2. 让玩家操作点、线、边、中点、角和面。
3. 观察图形变化中保持不变的关系。
4. 把关系用于面积最大化、路径最短、结构稳定。
5. 迁移到建筑、地图、迷宫、土地规划。

## 典型工具

- 点线面
- 中点
- 平行
- 周长
- 面积
- 勾股定理
- 对称

## 案例要点

- 任意四边形中点连线形成平行四边形，是“惊奇几何”的好入口。
- 游戏中可设计为：同样周长的围栏，正方形能圈出更大土地。
- 错误反馈应是路太长、地不够、结构不稳。
