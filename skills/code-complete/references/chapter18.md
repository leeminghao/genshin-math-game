# Chapter 18 - 布局和风格

## 核心观点

- 布局不是装饰，而是表达代码结构和意图的工具。
- 一致风格能降低团队认知成本。
- 好布局帮助读者快速看出控制结构、语句分组、注释关系和模块边界。

## 操作步骤

1. 遵守项目现有格式化规范。
2. 用缩进表达块层次。
3. 用空行分隔概念段落。
4. 对长语句和复杂表达式进行可读换行。
5. 保持控制结构、单条语句、注释、子程序和文件布局一致。
6. 使用自动格式化工具避免风格争论。

## 典型工具

- 格式化器。
- 布局规范。
- 代码风格检查。
- 控制结构布局模板。
- 文件组织模板。

## 案例要点

- 本章详细讨论控制结构、单条语句、注释、子程序、文件和模块布局。
- 布局质量影响评审效率，混乱布局会掩盖真实逻辑问题。
