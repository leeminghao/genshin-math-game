# Chapter 05 - 高质量子程序特点

## 核心观点

- 子程序是控制复杂度的基本单位。
- 高质量子程序应命名准确、强内聚、低耦合、长度适当、参数清楚，并具有防错能力。
- 子程序应围绕一个明确意图组织，而不是为了复用或方便随意抽取。

## 操作步骤

1. 说明创建该子程序的理由：降低复杂度、避免重复、隔离变化、隐藏顺序或处理错误。
2. 检查名称是否表达结果或动作。
3. 检查是否只承担一个主要职责。
4. 检查参数数量、顺序、输入输出方向和合法范围。
5. 检查是否有隐藏副作用。
6. 检查错误处理和防御式编程是否充分。
7. 对过长或低内聚子程序进行拆分。

## 典型工具

- 子程序质量检查表。
- 内聚/耦合评估。
- 参数表。
- 防御式编程检查。
- 例程提取与命名审查。

## 案例要点

- 书中强调创建子程序的原因包括降低复杂度、避免重复、支持测试和隐藏实现。
- 强内聚与松耦合是子程序质量的核心；长度不是唯一指标，职责清晰更重要。
