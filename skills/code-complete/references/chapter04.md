# Chapter 04 - 建立子程序步骤

## 核心观点

- 子程序构建应遵循小型工程流程：设计、编码、检查、修正。
- PDL / 伪代码可以帮助先表达意图，再翻译成具体语言。
- 好子程序不是一次写成，而是通过逐步细化和检查形成。

## 操作步骤

1. 明确子程序职责和调用契约。
2. 用自然语言或 PDL 写出步骤。
3. 检查伪代码是否完整、简单、无隐藏分支。
4. 将伪代码逐步转换成代码。
5. 做桌面检查、编译检查、单元测试和边界检查。
6. 根据发现的问题调整结构，而不是只修局部语句。

## 典型工具

- PDL / 伪代码设计。
- 子程序契约表。
- 子程序检查表。
- 桌面检查。
- 小步编码与小步验证。

## 案例要点

- 本章把子程序建立拆成设计、编码、检查几个步骤，强调编码前先理清逻辑。
- PDL 的价值在于让程序员先关注问题和步骤，而不是过早陷入语言细节。
