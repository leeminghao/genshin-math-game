# Chapter 12 - 复杂数据类型

## 核心观点

- 复杂数据类型用于表达复杂关系，能显著降低控制逻辑复杂度。
- 记录/结构、表驱动方法和抽象数据类型是组织复杂数据的关键工具。
- 数据抽象应保护不变量，并隐藏表示细节。

## 操作步骤

1. 判断数据是否应从多个基础变量提升为结构或对象。
2. 把相关字段组合，并定义合法状态。
3. 对大量条件分支考虑表驱动方法。
4. 对复杂数据提供抽象接口，而不是暴露内部结构。
5. 检查调用者是否依赖内部表示。
6. 为复杂数据类型设计构造、验证和测试。

## 典型工具

- 结构/记录设计表。
- 表驱动方法。
- ADT / 抽象数据类型。
- 不变量检查表。
- 数据封装审查。

## 案例要点

- 本章强调表驱动方法可把复杂控制逻辑转为数据配置。
- ADT 的价值在于让调用者使用概念操作，而不是操纵内部表示。
