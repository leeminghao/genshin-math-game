# Chapter 25 - 单元测试

## 核心观点

- 单元测试验证局部行为，是创建质量的重要组成部分。
- 测试应覆盖正常路径、边界条件、错误路径和典型缺陷。
- 好测试不仅发现问题，也保护后续修改。

## 操作步骤

1. 明确被测单元的契约和边界。
2. 为正常输入、边界输入、异常输入设计用例。
3. 检查典型错误：边界、空值、溢出、状态、顺序、资源。
4. 使用测试支持工具自动执行。
5. 记录重要缺陷和测试结果。
6. 对修复过的 bug 增加回归测试。

## 典型工具

- 单元测试框架。
- 边界值分析。
- 等价类划分。
- 测试用例表。
- 覆盖率工具。
- 回归测试。

## 案例要点

- 本章讨论单元测试的一般方法、技巧、典型错误、支持工具和测试记录。
- 单元测试不等于随手跑一下，而是系统设计局部验证。
