# Chapter 21 - 项目大小如何影响创建

## 核心观点

- 项目规模越大，沟通、集成、缺陷、计划和生产率问题越复杂。
- 小项目习惯不能直接套到大项目。
- 创建活动必须随规模调整正式程度和管理方法。

## 操作步骤

1. 判断项目规模：人数、周期、代码量、依赖、风险和交付约束。
2. 根据规模调整需求、设计、评审、测试和集成流程。
3. 对大项目增加接口契约、配置管理、代码评审和度量。
4. 对小项目保持轻量，但保留关键质量控制。
5. 跟踪规模增长带来的沟通和缺陷趋势。

## 典型工具

- 项目规模评估。
- 规模-流程匹配表。
- 缺陷密度统计。
- 生产率度量。
- 集成风险表。

## 案例要点

- 本章讨论项目大小对开发活动、错误和生产效率的影响。
- 规模增加不是线性问题，协调和错误成本会显著上升。
