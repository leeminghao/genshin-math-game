# Chapter 13 - 顺序程序语句

## 核心观点

- 顺序语句应让执行依赖清楚可见。
- 隐藏的顺序依赖会让代码脆弱，难以重排和维护。
- 与顺序无关的语句应通过分组和空行表达逻辑关系。

## 操作步骤

1. 识别哪些语句必须按固定顺序执行。
2. 将依赖关系靠近放置，并用名称或结构表达。
3. 避免让后续语句依赖远处的隐式副作用。
4. 对无顺序依赖的语句按概念分组。
5. 用空行和局部变量强化阅读路径。
6. 对关键顺序依赖增加简短说明或封装成子程序。

## 典型工具

- 顺序依赖检查表。
- 语句分组。
- 局部封装。
- 副作用追踪。

## 案例要点

- 本章区分必须有明确顺序和与顺序无关的语句。
- 清楚表达顺序依赖能降低维护者重排代码时引入缺陷的风险。
