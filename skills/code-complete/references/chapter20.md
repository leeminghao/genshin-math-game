# Chapter 20 - 编程工具

## 核心观点

- 工具能放大程序员能力，减少机械错误，提高一致性和反馈速度。
- 编程环境不应只依赖编辑器，还应包含设计、源码、执行、测试、调试和自动化工具。
- 优秀程序员会建立自己的小工具来消除重复劳动。

## 操作步骤

1. 盘点当前开发流程中的重复、易错和慢反馈环节。
2. 引入或配置源代码管理、构建、测试、格式化、静态检查和调试工具。
3. 将常用检查自动化。
4. 对项目专有重复任务编写小工具。
5. 确保工具链可被团队共享和复现。
6. 持续改进开发环境。

## 典型工具

- IDE / 编辑器配置。
- 版本控制。
- 构建系统。
- 静态分析。
- 测试运行器。
- 调试器。
- 脚本和代码生成工具。

## 案例要点

- 本章区分设计工具、源码工具、执行代码工具和面向工具的环境。
- 自建工具是专业工程习惯的一部分，不是额外爱好。
