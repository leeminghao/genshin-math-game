# Chapter 32 - 软件开发方法的有关问题

## 核心观点

- 软件开发方法的首要任务是控制复杂性。
- 程序首先是写给人读的，其次才是让计算机执行。
- 方法、约定和过程都应根据问题规模选择，不能固执套用。

## 操作步骤

1. 识别当前系统的主要复杂性来源。
2. 选择适合项目规模和风险的开发过程。
3. 优先提升人类可理解性。
4. 使用约定降低沟通成本。
5. 根据问题范围编程，不做无关泛化。
6. 警惕偶然事件、重复问题和固执己见。
7. 定期复盘方法是否仍然适用。

## 典型工具

- 复杂性控制清单。
- 开发过程选择表。
- 编码约定。
- YAGNI 检查。
- 复盘模板。
- 风险扫描。

## 案例要点

- 本章强调克服复杂性、精选开发过程、首先为人编写程序、注重约定。
- 不要固执己见是重要工程原则：证据优先于偏好。
