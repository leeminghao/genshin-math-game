# Chapter 08 - 生成数据

## 核心观点

- 数据设计是程序设计的中心，控制结构往往由数据结构决定。
- 创建合适的数据类型能表达领域概念、减少错误并提升可维护性。
- 初始化和数据说明不清，会制造隐蔽缺陷。

## 操作步骤

1. 识别程序中的核心数据对象、状态和生命周期。
2. 为领域概念创建明确类型，而不是滥用基础类型。
3. 检查数据是否有合法范围、单位、默认值和不变量。
4. 在创建点或明确初始化阶段初始化数据。
5. 避免让调用者依赖未说明的数据约定。
6. 让数据说明靠近使用位置，减少误解。

## 典型工具

- 数据识别表。
- 自定义类型清单。
- 不变量列表。
- 初始化检查表。
- 数据生命周期图。

## 案例要点

- 本章强调自建数据类型能让程序更接近问题域。
- 数据初始化是常见缺陷来源，应作为编码检查重点。
