# Chapter 33 - 从何处获取更多的信息

## 核心观点

- 软件工程知识持续演进，程序员需要持续学习。
- 高质量信息来源包括书籍、期刊、专业组织、经验报告和项目复盘。
- 个人经验必须与外部知识结合，否则容易固化为局部习惯。

## 操作步骤

1. 为当前问题查找对应主题资料，而不是泛泛学习。
2. 使用权威书籍、论文、文档和成熟项目作为参考。
3. 建立团队知识库，沉淀项目经验和决策。
4. 定期更新工具链和工程实践。
5. 参加技术社区或专业组织，获取外部反馈。
6. 将学到的方法通过小实验引入项目。

## 典型工具

- 技术资料库。
- 团队知识库。
- 阅读清单。
- ADR / 决策记录。
- 技术分享。
- 实践试点记录。

## 案例要点

- 本章列出软件领域资料库、创建信息、期刊和专业组织。
- 持续学习不是阅读本身，而是把可靠知识转化为项目中的可执行改进。
