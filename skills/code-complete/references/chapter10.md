# Chapter 10 - 变量

## 核心观点

- 变量质量取决于作用域、生命周期、赋值时机和职责单一性。
- 作用域越大、生命周期越长、职责越多，理解和出错成本越高。
- 全局变量是复杂度和隐式耦合的重要来源，应谨慎使用。

## 操作步骤

1. 将变量作用域缩到能满足需求的最小范围。
2. 缩短变量生命周期，避免长时间处于半有效状态。
3. 在靠近首次使用处声明和初始化。
4. 保证一个变量只表达一个概念。
5. 检查变量赋值是否集中、清楚、可追踪。
6. 对全局变量评估替代方案：参数、对象状态、上下文、依赖注入。

## 典型工具

- 变量作用域检查。
- 生命周期图。
- 单一职责变量检查表。
- 全局变量风险表。
- 赋值点追踪。

## 案例要点

- 本章强调数据结构与控制结构相关；变量设计不当会让控制逻辑复杂。
- 全局变量看似方便，实际增加模块间隐式依赖和测试难度。
