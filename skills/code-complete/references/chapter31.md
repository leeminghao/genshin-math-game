# Chapter 31 - 个人性格

## 核心观点

- 程序员个人性格会直接影响代码质量。
- 好程序员需要聪明但谦虚、好奇、诚实、愿意交流合作，并能建立稳定习惯。
- 技术能力不足可以学习，缺乏诚实和谦虚会持续制造工程风险。

## 操作步骤

1. 在评审和调试中默认自己可能错。
2. 对不理解的代码、工具和缺陷保持好奇。
3. 如实暴露风险、缺陷和不确定性。
4. 主动沟通接口、假设和进度。
5. 用自动化减少重复劳动。
6. 把好实践变成日常习惯。

## 典型工具

- 个人工程习惯清单。
- 复盘记录。
- 代码评审反馈记录。
- 自动化任务清单。
- 风险公开表。

## 案例要点

- 本章讨论聪明和谦虚、好奇、诚实、交流合作、创造力、懒惰和习惯。
- “懒惰”在工程上可以表现为愿意自动化重复工作。
