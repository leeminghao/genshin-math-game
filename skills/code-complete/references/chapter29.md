# Chapter 29 - 代码调整技术

## 核心观点

- 代码调整技术包括循环、逻辑、数据转换、表达式、子程序等层面的局部优化。
- 局部优化应服从整体性能目标，不能牺牲结构和正确性。
- 汇编或低层重写是最后手段。

## 操作步骤

1. 从已测出的热点开始，不全局撒网。
2. 先优化算法和数据结构，再考虑语句级调整。
3. 检查循环中的重复计算、边界检查和不必要分配。
4. 简化逻辑和表达式。
5. 减少不必要数据转换。
6. 对子程序调用、内联或拆分做测量验证。
7. 保留调整原因和基准数据。

## 典型工具

- 热点代码清单。
- 循环优化检查表。
- 表达式简化。
- 分配/拷贝分析。
- 微基准。
- 调整记录。

## 案例要点

- 本章列出循环、逻辑、数据转换、表达式、子程序和汇编再编码等调整方向。
- 这些技术只有在瓶颈路径上才有价值。
