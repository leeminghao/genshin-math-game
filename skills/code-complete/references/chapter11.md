# Chapter 11 - 基本数据类型

## 核心观点

- 基本数据类型并不简单，每种类型都有典型陷阱。
- 常量、整数、浮点、字符串、布尔、枚举、数组、指针都需要按类型特性防错。
- 使用命名常量和枚举能减少魔法值、边界错误和表达不清。

## 操作步骤

1. 用命名常量替代裸值。
2. 检查整数溢出、符号、边界和单位。
3. 对浮点比较使用容差或领域规则。
4. 对字符串处理检查编码、长度、空值和边界。
5. 布尔变量应表达明确命题，避免双重否定。
6. 用枚举表达有限状态集合。
7. 数组访问必须检查索引和容量。
8. 指针/引用必须明确所有权、空值和生命周期。

## 典型工具

- 基本类型风险清单。
- 魔法值扫描。
- 边界值测试。
- 空值检查。
- 指针生命周期审查。

## 案例要点

- 本章覆盖常数、整数、浮点、字符串、逻辑变量、枚举、数组和指针。
- 每种基本类型都有常见错误模式，不能只依赖语言编译器兜底。
