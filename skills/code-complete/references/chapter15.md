# Chapter 15 - 循环语句

## 核心观点

- 循环是常见缺陷来源，关键在初始化、终止条件、循环变量和边界。
- 选择正确循环类型能让意图更明显。
- 复杂循环应从内部逻辑向外构建，并保持每次迭代职责清楚。

## 操作步骤

1. 选择合适循环类型：计数、条件、迭代集合、无限循环加退出。
2. 明确初始化、终止条件和步进逻辑。
3. 检查边界：空集合、单元素、最后一个元素、越界。
4. 保持循环体短小，必要时提取子程序。
5. 避免在循环中修改多个控制变量。
6. 检查循环和数组/集合索引关系。
7. 为循环编写边界测试。

## 典型工具

- 循环边界检查表。
- 循环不变量。
- 从里到外构建循环。
- 集合迭代替代索引循环。
- 边界值测试。

- 循环与数组关系紧密，边界错误是最典型风险之一。
