# Chapter 22 - 创建管理

## 核心观点

- 创建活动需要管理：代码、配置、计划、度量、人员状态和上下游关系。
- 管理不是压迫程序员，而是建立稳定、可预测、可改进的创建环境。
- 程序员是普通人，会受压力、疲劳、沟通和组织环境影响。

## 操作步骤

1. 使用已有高质量代码和库，避免重复造轮子。
2. 建立配置管理和版本控制策略。
3. 为创建活动估算和计划时间。
4. 收集缺陷、进度、测试和评审数据。
5. 关注程序员负荷、沟通和工作环境。
6. 与管理者沟通风险、事实和取舍。

## 典型工具

- 配置管理。
- 创建计划。
- 度量看板。
- 代码复用清单。
- 风险沟通模板。
- 工作负荷检查。

## 案例要点

- 本章包含使用好的代码、配置管理、计划评估、度量和如何对待上司等主题。
- 创建管理既包含技术资产，也包含人的现实因素。
