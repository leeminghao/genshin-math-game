# 第9章 问题出在哪里？

## 核心观点

- 数学卡住时，最重要的是定位问题，而不是继续堆步骤。
- 错误答案通常暴露的是某个直觉断点：对象没看见、关系没连上、单位不稳定、符号没内化。
- 诊断比纠正更重要，因为纠正只能处理表面错误。
- 学习者需要知道自己到底在哪里失去清晰感。

## 操作步骤

1. 让学习者复述自己以为题目在问什么。
2. 检查对象、数量、单位、关系、操作顺序是否明确。
3. 要求学习者画出或摆出自己的理解。
4. 找到图像、动作、语言和符号之间不一致的位置。
5. 针对断点重建经验，再回到计算。

## 典型工具

- 错误类型标注
- 直觉断点诊断表
- 画图复述
- 单位检查表
- 关系箭头图

## 案例要点

- 这一模块应被理解为全书方法论中的“诊断层”：数学困难不是笼统的不懂，而是具体机制断裂。
- 典型案例可围绕儿童把数字当孤立符号、忽略单位、无法解释等量关系来设计。
- 关键不是给出标准答案，而是暴露学习者脑中实际看到的东西。
