# 第19章 抽象而灵活

## 核心观点

- 抽象能力有生理和心理基础，并不是固定天赋。
- 人脑可以通过层级特征提取形成概念，类似从低级特征走向高级识别。
- 直觉可以被训练、重塑和迁移。
- 好的数学学习要让抽象保持灵活，而不是变成死定义。

## 操作步骤

1. 从具体样例中提取共同特征。
2. 对比相似但不同的样例，区分关键特征和无关特征。
3. 让学习者用自己的语言命名抽象关系。
4. 在多个表征中重建同一抽象。
5. 用新样例检查抽象是否灵活。

## 典型工具

- 样例/非样例对照
- 特征提取表
- 多表征迁移
- 概念边界图
- 变式练习

## 案例要点

- 书中借视觉错觉、神经元、深度学习等类比说明抽象来自层级加工。
- 关键案例要点是：概念不是单个定义，而是大量经验中稳定出来的可迁移结构。
- 数学直觉的训练应通过多样经验重塑感知。
