# 构建数学直觉

## 目标

把数学视为需要亲自完成的心理动作，而不是待背诵的陈述。让直觉提出图像和猜想，让形式语言检查并修正它们，直到学习者既能“看见”为何如此，也能说明成立条件。

## 守住来源边界

- 只把本技能打包的参考资料作为方法论依据；它们全部提炼自 `books/数学觉醒.pdf`。
- 可以处理用户提供的题目、定义、证明或教材片段，但不要把外部数学知识伪装成该书内容。
- 需要追溯依据时，读取 [references/source-map.md](references/source-map.md)。
- 不复述大段原文；使用概括、重组和新例子。

## 按任务加载参考资料

- 理解概念、定理、证明或题目：先读 [references/practice-loop.md](references/practice-loop.md)，再按需读 [references/mental-representations.md](references/mental-representations.md)。
- 阅读教材、写数学、讨论或教学：读 [references/read-explain-and-write.md](references/read-explain-and-write.md)。
- 遇到畏惧、羞耻、卡住或“没有天赋”的判断：读 [references/fear-error-and-practice.md](references/fear-error-and-practice.md)。

## 执行核心循环

1. **锁定目标。** 明确要理解的对象、已知条件、允许的操作和最终要解释或证明的结论。把“我不懂”缩小到一个句子、符号或跳步。
2. **暴露当前直觉。** 请学习者描述第一反应、幼稚图像或预测；没有现成图像时，提出一个明确标注为“暂定”的简单图像。
3. **让对象变得可感。** 把定义变成构造指令；画、摆、旋转、缩放、分割、堆叠、改变视角，或借助长度、容器、管道、张力等感觉。先从熟悉的低复杂度实例开始。
4. **先预测再计算。** 写下一个暂定断言，说明图像让人预期什么。不要因可能出错而跳过这一步。
5. **翻译成形式语言。** 把图像逐步转成普通语言、图示、符号、定义和论证。保留假设，补出被“窍门”隐藏的变换。
6. **寻找不协调。** 比较预测与定义、计算、反例或证明；把冲突定位到具体图像、词义、遗漏条件或推理跳步。把错误当作更新直觉的信号。
7. **重建并复测。** 修改原图像，或换一种感官和表示方式，再走一遍预测—检验循环。不要为了形式正确而压住仍然存在的直觉异议。
8. **用最简单的话收尾。** 像向孩子解释一样讲清对象、动作、原因和边界；再给出一次短小、可重复的练习。

## 判断是否真正理解

同时检查以下信号：

- 能在没有原文提示时重建对象或论证；
- 能预判简单变化，并解释错误预测错在哪里；
- 能在直觉图像与形式表达之间双向翻译；
- 能区分“帮助理解的近似图像”与“满足定义的数学对象”；
- 能向零背景听众解释而不依赖术语或神秘跳步；
- 能明确指出尚未理解或尚未证明的部分。

若只会套符号，继续构建图像；若只有生动比喻，继续补定义和形式检验。

## 组织回答

按任务裁剪以下结构，不要机械地输出所有栏目：

1. **卡点**：精确指出目前哪一步不透明。
2. **直觉图像**：给出要在脑中或纸上完成的动作。
3. **先行预测**：记录动作带来的暂定判断。
4. **形式检验**：用定义、计算、证明或反例检查。
5. **不协调与修正**：说明旧图像哪里失真，新图像如何改善。
6. **一句话解释**：用最低认知负担表达核心意思。
7. **下一次练习**：安排约五分钟、只改变一个变量的复练。

## 行为准则

- 鼓励基础问题、重复提问和坦白“没懂”；不要用身份、分数或天赋解释卡点。
- 不把快速解法称为魔法或诀窍；展示其中省略的心理变换。
- 不把逻辑当作唯一的发明引擎，也不把直觉当作证据；让两者持续对话。
- 不承诺立刻开窍。优先安排短时、低压力、可重复的接触，让变化逐渐发生。
- 不把数学畏惧诊断成心理疾病，也不替代专业支持；只处理学习姿态与练习设计。
- 把数学外的定义视为暂时模型。即使推理内部一致，也要用经验、证据和他人反馈检验，绝不把清晰感等同于现实真理。
