# 第03章 概念：提出与筛选

## 核心观点

- 产品概念来自“核心用户 + 刚性需求 + 典型场景 + 产品概念 + 竞争优势”。
- 好想法要经过筛选：内部看能力和意愿，外部看价值和成本。
- 产品概念不是灵感句子，而是可被验证、可被放弃、可被投资判断的方向。
- 概念筛选的目标是减少资源浪费，把有限投入放到更可能成立的方向上。

## 操作步骤

1. 定义核心用户：具体到可识别、可触达、可排除。
2. 定义刚性需求：频率、强度、付费意愿、替代成本或战略必要性。
3. 定义典型场景：用户在何时何地因何触发需求。
4. 写出产品概念和竞争优势。
5. 用能力、意愿、价值、成本四个维度筛选。
6. 给出继续验证、暂缓、放弃或调整方向的结论。

## 典型工具

- 产品概念句式：为谁、在什么场景、解决什么问题、提供什么方案、为什么更好。
- 概念筛选矩阵：能力、意愿、价值、成本。
- 机会评分卡：用户痛点、市场空间、差异化、可达性、资源匹配。
- 竞争替代分析：直接竞品、间接替代、用户现有做法。

## 案例要点

- 智能长命锁案例展示如何从核心用户、刚性需求、典型场景推出产品概念。
- 淘宝首页案例说明产品概念会随用户、流量、商业和生态变化而演进。
- 阿里旺旺和 B12 的方向思考用于说明：概念是否成立，不只看点子，还要看组织能力、投入意愿、外部价值和实现成本。
