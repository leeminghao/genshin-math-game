# 第01章 初识：大话产品经理

## 核心观点

- 产品经理不是画原型的人，而是连接用户、业务、技术、设计、运营和组织资源的人。
- 产品经理的关键成长是思维切换：从学生到职场、从用户到产品经理、从现象到本质。
- 好产品经理需要同理心、抽象能力、判断力、沟通协作和持续学习能力。
- 产品经理日常工作围绕发现问题、定义需求、协调资源、推动落地和持续优化展开。

## 操作步骤

1. 识别产品经理在当前项目中的责任边界：需求、方案、项目推动、数据、运营或商业。
2. 从用户视角收集现象，再从产品经理视角抽象成问题。
3. 把问题拆成用户价值、业务价值、技术可行性和协作成本。
4. 与周边团队建立共同语言：目标、范围、交付物、时间、风险。
5. 用事实和判断推动决策，而不是只转述需求。

## 典型工具

- 角色边界表：产品、研发、设计、测试、运营、销售、客服责任。
- 现象到本质分析表：用户反馈、真实问题、根因、机会。
- 跨职能任务板：目标、Owner、交付物、依赖、风险。
- 产品经理能力雷达：同理心、抽象、沟通、项目推进、商业理解。

## 案例要点

- 宝洁品牌经理故事用于说明产品经理岗位源自对“完整产品结果”的负责。
- 从项目经理到产品经理的差别：项目经理偏交付管理，产品经理要对用户价值和商业结果负责。
- 章节强调产品经理不能只站在个人使用体验上，要能从组织、市场和系统角度看问题。
