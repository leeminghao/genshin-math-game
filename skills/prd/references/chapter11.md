# 第11章 蜕变：从产品助理到 CEO

## 核心观点

- 产品经理成长不是职位升级，而是责任范围从需求执行扩展到商业闭环和组织影响。
- 七层修炼：需求细化与研发跟进、主动挖掘与项目管理、完整产品与大局观、产品线与带团队、成功案例与影响力、商业闭环与全职能管理、从自己成功到助人成功。
- 长期看，产品经理能力会泛化为组织中更多人的基础能力。
- 产品经理的归宿是广义创业：主动发现问题、组织资源、创造价值。

## 操作步骤

1. 判断当前能力层级和主要短板。
2. 从被动接需求转向主动发现问题。
3. 从单功能负责扩展到完整产品结果负责。
4. 从产品交付扩展到商业、运营、组织和团队管理。
5. 建立成功案例和复盘资产。
6. 用产品方法管理自己的职业成长或创业行动。

## 典型工具

- 产品经理七层能力自评表。
- 成长路线图。
- 项目复盘库。
- 影响力地图：用户、团队、业务、行业。
- 创业启动五步清单。

## 案例要点

- 在人力资源部做产品经理的案例说明产品方法可以迁移到内部系统、学习平台和组织创新。
- 从产品经理到创业者强调：创业是更完整、更高风险的产品实践。
- 对 PRD 的启示：高级产品文档不只定义功能，还应体现商业闭环、组织协同和长期责任。
