# 第09章 运营：先验证再扩张

## 核心观点

- 产品和运营不是对立关系，运营帮助产品完成价值传递、用户验证和规模扩张。
- 需求、功能要转化为用户可感知的卖点。
- 不同生命周期阶段需要不同运营目标。
- 销售、服务、市场、品牌、公关都与产品价值实现有关。
- 先验证再扩张，避免在价值未证实时盲目放大。

## 操作步骤

1. 从功能中提炼用户卖点。
2. 定义当前阶段：冷启动、验证、增长、成熟、衰退。
3. 匹配运营目标：获取、激活、留存、转化、召回或口碑。
4. 设计上线和反馈闭环。
5. 将运营反馈回流到需求池和迭代计划。
6. 评估销售、服务、市场、品牌、公关对产品的影响。

## 典型工具

- 卖点提炼表：功能、用户价值、表达方式、证据。
- 运营需求模板。
- 生命周期阶段表。
- AARRR 或漏斗指标。
- 用户反馈闭环表。
- 上线计划和复盘表。

## 案例要点

- 星巴克综合案例用于说明运营不是单点动作，而是体验、服务、品牌和商业的组合。
- 服务是广义用户运营，提示产品设计不能只覆盖线上功能，也要覆盖售后和体验闭环。
- 对 PRD 的启示：上线方案和运营验证是 PRD 的必要组成，不是后续补充。
