# 第10章 案例：商业模式、创新与行业

## 核心观点

- 产品必须回到商业模式、业务模式和盈利模式的区分与闭环。
- 分析商业模式要看“100 块去哪儿了”：收入如何产生、成本如何分配、谁获得价值。
- 创新不是口号，不同组织有不同创新陷阱。
- 行业案例分析要结合用户、场景、供给、成本、网络效应和商业可持续性。

## 操作步骤

1. 区分商业模式、业务模式和盈利模式。
2. 拆解收入、成本、毛利、获客、履约、服务和风险。
3. 识别产品创新属于体验创新、效率创新、模式创新还是技术创新。
4. 判断组织类型对应的创新坑：创业公司、大公司、传统企业。
5. 用行业案例校验产品假设，而不是只看功能相似度。
6. 给出商业可行性结论：继续、转向、缩小验证、暂停。

## 典型工具

- 商业模式画布。
- 单位经济模型。
- 100 元流向图。
- 创新风险清单。
- 行业案例分析表。
- 竞争替代和价值链分析。

## 案例要点

- O2O、知识类共享经济、中老年广场舞案例展示不同人群、供给结构和商业约束下的产品判断。
- 创业公司创新坑：资源不足却追求大而全，未验证就扩张。
- 大公司创新坑：组织惯性、指标冲突、资源看似充足但决策缓慢。
- 传统企业创新坑：把互联网当渠道或工具，而不是重构用户价值链。
