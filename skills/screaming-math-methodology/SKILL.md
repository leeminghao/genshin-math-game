# Screaming Math Methodology

Use this skill to summarize, review, or restructure 《尖叫的数学》 as a history of mathematical concept breakthroughs.

Core stance:

> 数学不是一套现成公式，而是人类在面对“无法记录、无法表示、无法测量、无法解释、无法想象”的问题时，创造新符号、新对象、新规则和新空间的过程。

When the user asks to respect the book, preserve the book’s chapter order and separate source facts from methodological abstraction. Do not over-game, over-productize, or convert the book into generic “math is everywhere” material unless the user explicitly asks for application.

## Default Output Shape

For chapter/module summaries, use:

1. **总体方法论 thesis**
2. **章节/模块表**
3. **核心概念突破**
4. **跨章节递进路径**
5. **事实边界/推断说明**, when needed

Preferred table:

```text
章节/模块 | 核心问题 | 核心方法论 | 关键数学工具 | 概念突破
```

For shorter summaries:

```text

```

## Core Methodology Rules

Use these rules when analyzing or rewriting material based on 《尖叫的数学》:

1. **从问题进入概念。** Do not start with formulas; start with the crisis or need that made a concept necessary.
2. **区分记录、表示、证明、构造和解释。** A tally mark, a numeral, a proof, a formal object, and a physical model are different layers.
3. **追踪直觉障碍。** Identify what common-sense belief the chapter overturns: “nothing cannot be a number”, “all lengths are commensurable”, “curves cannot be measured”, “negative square roots are impossible”, “space is Euclidean”.
4. **保留历史张力。** Explain how concepts emerge through debates, failed attempts, paradoxes, and partial solutions.
5. **显示符号的力量。** Treat notation as a technology that changes what can be calculated, transmitted, and imagined.
6. **把失败当作方法论线索。** 化圆为方、第五公设、除以零、虚数困惑 are not side stories; they reveal the boundary of existing methods.
7. **从形式走向意义。** Many mathematical objects first work formally, then later gain geometric, physical, or philosophical interpretation.
8. **结尾回到自由创造。** The book’s final thesis is not utility alone, but mathematical freedom, beauty, and imagination.

## Concept Breakthrough Map

| Breakthrough | Before | After |
| --- | --- | --- |
| 计数记录 | Quantity exists only in immediate experience | Quantity can be externalized as marks, knots, or tokens |
| 位值制与零 | Symbols mostly name quantities | Position and absence become part of number structure |
| 证明 | Drawing and measuring suggest facts | Logical argument establishes universality |
| 无理数 | Number means whole-number ratio | Magnitude can exceed rational expression |
| π and circle measurement | Curves resist exact linear measurement | Approximation, constants, and limits organize curved space |
| 虚数 | Only “real” magnitudes count as numbers | Formal extensions create new calculable objects |
| 复平面 | Imaginary numbers seem meaningless | Complex numbers become geometric points and physical language |
| 非欧几何 | Euclidean space seems inevitable | Geometry depends on axioms, metric, and curvature |
| 数学自由 | Mathematics appears discovered from reality only | Mathematics also creates possible worlds that reality may later use |

## Review Checklist

When reviewing a summary, PRD, game design, curriculum, or analysis that uses this book, check:

- Does it preserve the seven-part structure: preface, six chapters, afterword?
- Does each module identify the historical or conceptual problem that forced the mathematics?
- Does it distinguish source facts from modern inference?
- Does it avoid reducing the book to a list of famous mathematicians?
- Does it avoid turning “数学之美” into vague praise without mechanism?
- Does it explain why each concept was shocking, counterintuitive, or liberating?
- Does it show the shift from concrete practice to symbolic/formal freedom?
- Does it connect virtual/formal objects such as 0, irrational numbers, imaginary numbers, and non-Euclidean spaces to later usefulness without pretending they were invented for that use?

## Common Failure Modes

Avoid:

- Turning 《尖叫的数学》 into a standard curriculum outline.
- Treating the book as a generic “math is useful” text.
- Summarizing chapters by topic only and omitting the conceptual crisis.
- Explaining 0, irrational numbers, π, imaginary numbers, and non-Euclidean geometry as if they were always obvious.
- Collapsing historical narrative into formulas.
- Overstating historical certainty where the book presents stories, legends, or contested origins.
- Mixing game design or product advice into source-faithful summaries unless requested.
