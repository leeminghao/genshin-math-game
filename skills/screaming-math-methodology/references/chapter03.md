# 第二章：表示虚无的数字0

## 核心观点

- 0 的突破在于把“没有”“空位”“虚无”变成可写、可定位、可运算的数学对象。
- 零最初不只是一个数，也是一种占位技术；位值制依赖空位才能表达数量级。
- 十进位值制的核心不是十进制本身，而是“同一符号因位置不同而有不同值”。
- 0 的概念长期带有哲学和逻辑张力：它既表示无，又作为符号存在。
- 零的运算边界暴露数学概念的困难，尤其是除以零的问题。

## 操作步骤

1. 先区分哲学虚无、语言中的“无”、占位符和数字 0。
2. 分析位值制：同一数码在个位、十位、百位具有不同数量级。
3. 说明空位的必要性：没有 0，308 和 38、803 和 83 等结构难以清楚区分。
4. 追踪零从点、空位、圆圈到数字符号的历史演进。
5. 讨论零的基础运算：a-a=0、a×0=0 等。
6. 对除以零保持边界意识：不要把早期错误理解成现代定论。
7. 说明零的传播：印度数学、阿拉伯传播、欧洲算术教育和商业计算。

## 典型工具

- 概念分层：虚无、词语、占位、数字、算符。
- 位值分析：符号值 = 本身数值 + 所在位置。
- 占位检查：找出一个数中 0 保持结构的位置。
- 运算边界：区分可定义运算和不可定义运算。
- 传播路径：印度 -> 阿拉伯数学 -> 地中海贸易与欧洲算术。

## 案例要点

- 中世纪关于虚无的讨论揭示“无”作为词语和对象之间的张力。
- 印度文献和寺庙碑文体现零作为符号逐渐具体化。
- 拉普拉斯对位值制的说明强调，十个符号足以表达任意数字的精妙性。
- 婆罗摩笈多等数学家为零建立运算法则，同时在除以零问题上仍有困难。
- 花拉子米、斐波那契等人推动印度数字和 0 向欧洲传播。
- 莎士比亚等文学案例体现 0 在文化语言中的多重含义。
