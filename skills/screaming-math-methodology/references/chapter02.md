# 第一章：计算时间和物件

## 核心观点

- 数学从记录开始：人类先需要保存数量、时间、债务和交换关系，才逐步发展出数字和计算。
- 刻痕、结绳、计数棒、奇普等工具说明，早期数学首先是一种外部记忆技术。
- 一一对应是计数的底层方法：一个刻痕、一个结、一个标记对应一个对象或一次事件。
- 分组计数让数量从简单罗列走向结构化，例如按 5、7、10、12 等分组。
- 数字概念晚于计数行为；能记录“和羊一样多”不等于已经拥有抽象数字语言。

## 操作步骤

1. 先识别现实需求：计日、清账、统计牲畜、记录交易、行政核算。
2. 将需求转化为“一一对应”的记录结构。
3. 分析记录媒介：骨头、木棍、绳结、算盘、种子、账本。
4. 观察是否出现分组：五个一组、七日周期、十进或十二进倾向。
5. 区分“痕迹记录”和“数字概念”：前者保存数量，后者可脱离具体对象运算。
6. 说明记数工具如何影响制度、交易、公平和信任。

## 典型工具

- 一一对应：对象和标记逐个匹配。
- 分组计数：按固定基数组织大量刻痕或记号。
- 外部记忆：把数量从脑中转移到物件上。
- 双联凭证：计数棒一分为二，用吻合关系保证账目可信。
- 跨文化比较：比较刻痕、结绳、奇普、算盘等不同记录技术。

## 案例要点

- 鲁滨孙用刻痕记录日子，体现记录时间的原始方法。
- 旧石器时代骨刻说明，计数和分组可能早于文字。
- 英国财政计数棒体现数学记录和行政制度的结合，也显示落后记录制度可能产生荒诞后果。
- 法国、意大利等地的面包、酒、赊账记录说明计数棒长期嵌入日常经济。
- 印加奇普和优巴纳说明，结绳和计算板可以形成复杂记录系统。
- 中国“结绳而治”等传统体现不同文明都有独立的数量记录实践。
