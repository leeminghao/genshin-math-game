## 一、产品定位与概览

**Matific** 是一家成立于 2012 年的以色列教育科技公司，主打 **K-6（4-12 岁）数学游戏化学习平台**。2016 年完成 4500 万美元 B 轮融资，产品覆盖 70+ 国家、50+ 语言，拥有 2000+ 互动活动、数十亿道已解题。

核心产品形态：
- **学生端**：游戏化冒险岛屿 + 自适应学习路径 + 训练区域
- **教师端**：课程规划、作业布置、自动批改、实时学情报告
- **家长端**：进度追踪、家长报告、时间管控

商业模式：B2B（学校/学区）+ B2C（家长订阅）。家庭版约 $19.99/单年级/年，$39.99/全 K-6/年。

## 二、内容体系：1660+ 活动的组织方式

中文站 `matific.com/zh/zh/home/maths/` 展示了 **1660 个数学活动/工作单**，按三条主线组织：

### 1. 按年级（K-9）
幼儿园、1-9 年级，每个年级有 60-200+ 个活动。

### 2. 按主题（22 大主题）
- 20 以内 / 100 以内 / 1000 以内 / 大数
- 数论、分数、小数、负数、实数
- 比率与比例、百分比、幂与根
- 顺序、代数和方程
- 二维几何、笛卡尔平面、3D 几何
- 测量、数据和统计、概率
- 数学思维、其他活动

### 3. 按课程标准
- Common Core（美国共同核心）
- Singapore Syllabus 2013 / 2021（新加坡数学课程）

### 4. 活动命名规律（可借鉴）
每个活动标题都包含 **"具体场景 + 数学动作 + 适用范围"**：
- `用数字和文字表示整数`（10000 以内）
- `游戏：运用策略来乘以整数`（100 以内）
- `用单位正方形测量矩形的面积`
- `计算概率（视觉模型、分数）`
- `游戏：求解逻辑问题的策略（分割方块）`

配图文件名也常使用场景化命名：`SpinningWheelProbabilityFractions`、`AreaOfRectanglesArea`、`HoppingOnTheNumberLineAdditionUpTo20`。

## 三、五大教学原则（Pedagogical Principles）

Matific 官网明确将其核心竞争力总结为 **5 点教学法**，由斯坦福、哈佛、伯克利、爱因斯坦研究所专家参与开发：

### 1. Conceptual Understanding（概念理解）
- 从 Concrete（具体）→ Symbolic（符号）→ Abstract（抽象）的渐进路径
- 使用 Multiple Metaphors（多种隐喻）帮助孩子建立可迁移的数学模型
- 螺旋式学习（Spiral Learning）与"提前播种"（Seeding Ahead）
- 强调跨主题连接，而非孤立技能
- **错误答案三步反馈**：鼓励孩子回顾错误 → 提供图示建议 → 给出解题步骤提示

### 2. Critical Thinking（批判性思维）
- 鼓励孩子质疑定义和结论："什么时候适用？""需要什么条件？"
- 培养问题解决能力，尤其是"没有明确算法"的开放性问题
- ** accountability（自我负责）**：让孩子看到自己的错误如何导致逻辑结果
- 允许多种策略、多种解法

### 3. Meaningful Context（有意义的情境）
- 把数学放进真实、自然的场景中
- 使用孩子熟悉的事物：电影、游戏、日常生活
- 避免牵强情境（例如：6 个鸡蛋放在蛋盒里，而不是森林里 6 个蘑菇）
- **Intrinsic Feedback（内在反馈）**：反馈来自问题情境本身，而非外部评判

### 4. Personalised Learning（个性化学习）
- 自适应算法调整难度和路径
- 无时间压力，可反复尝试
- **Activity Variants（活动变体）**：同一游戏外观相同，但难度不同，教师可分配不同变体给不同学生
- 支持异质课堂：同伴学习、拓展题（riddles/brain teasers）、跨学科内容
- 根据学生实际答案提供个性化反馈和提示

### 5. Intrinsic Engagement（内在参与）
- 严谨的游戏化环境，不让 UX 盖过教学
- **减少数学焦虑**：没有"唯一正确答案"的压力，错误是学习过程的一部分
- 激发好奇心和坚持（perseverance）
- 给予失败的自由
- **Technology as teaching aid**：不只是数字练习纸，而是虚拟实验室和交互环境
- **Learn by Doing**："我听见的我会忘记，我看见的我会记住，我做过的我会理解"

## 四、游戏化与交互设计特点

### 1. 元游戏结构：冒险岛屿
- 学生自定义头像探索"Matific 冒险岛屿"
- 解锁新区域、收集宝藏、获得新头像装扮
- 完成关卡获得 pixels（像素）和 coins（金币）
- 5 星制评价：全部答对得 5 星；答错可返回重练直到正确

### 2. 三重奖励系统
- 三重宝箱（Triple Chest）鼓励学生重复练习以掌握技能
- 即时视觉反馈和进度条

### 3. 多人在线竞技场
- 学生可与全球同龄人一起参加虚拟课堂
- 强调同伴学习和竞争/合作

### 4. 训练区域（Training Zone）
- 学生可自主选择特定主题进行针对性练习
- 算法根据薄弱点推送合适难度的活动

### 5. 音频与辅助功能
- 为低龄儿童提供语音指令朗读
- 内置操作动画演示
- 高对比度、灰度、大字体、高亮链接等无障碍选项

### 6. 离线可用
- 支持离线使用，降低网络依赖

## 七、对《数学小镇》原型的借鉴点

### 可直接吸收的机制
1. **具体场景命名**：每个关卡都要包含"场景 + 数学动作 + 适用范围"
2. **Intrinsic Feedback**：错误反馈来自情境本身（蛋糕塌了、桥断了），而不是一个红色叉号
3. **多种解法认可**：同一道比例题允许不同调整策略
4. **无时间压力 + 可重复尝试**：让孩子有安全感地探索
5. **提前播种**：在正式教某个概念前，先用直觉版本让孩子接触
6. **跨主题连接**：同一个比例概念出现在烘焙、调颜料、做音乐、建花园中

### 可扩展的元游戏
1. **冒险地图/小镇建设**：用完成的数学任务解锁新建筑、新居民、新装扮
2. **像素/金币 + 星级**：每关 1-3 星，根据准确率和尝试次数评分
3. **训练区域**：让孩子针对薄弱概念自主练习
4. **家长/教师面板**：显示孩子在哪些生活场景里数学用得最好

### 需要警惕的坑
1. **不要让游戏化盖过数学**：Matific 明确说"engaging UX does not overshadow the pedagogy"
2. **避免牵强情境**：6 个鸡蛋在蛋盒里比森林里 6 个蘑菇更真实
3. **反馈信息要适度**：太多或太少都不利于理解错误
