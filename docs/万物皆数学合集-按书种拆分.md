# 《万物皆数学》合集按书种拆分

说明：`books/万物皆数学.epub` 实际是一个数学通识合集，内部包含多本书。以下拆分基于 EPUB 目录结构，按“这本书在知识体系中的作用”分类，而不是按文件顺序分类。

## 总体拆分

| 书种 | 包含书目 | 核心作用 | 适合进入《我的数学岛》的方式 |
| --- | --- | --- | --- |
| 趣味启蒙型 | 《12堂魔力数学课》《用数学魔法改变人生》 | 用魔术、游戏、生活案例激发兴趣，让孩子先觉得数学有用、有趣、能解释现象 | 作为新手任务、轻量谜题、低门槛互动机关 |
| 基础体系型 | 《极简数学》 | 建立数、比例、代数、几何、统计、概率的基础知识框架 | 作为世界底层规则库，转化为采集、合成、建造、交易、自动化规则 |
| 现实决策型 | 《救命的数学》《魔鬼数学：大数据时代，数学思维的力量》 | 训练概率、统计、指数、算法、风险和反直觉判断 | 作为经营、市场、灾害、医疗、骗局识别、资源调度系统 |
| 艺术建筑型 | 《感官的盛宴（万物皆数学）》 | 讲透视、空间、比例、建筑、艺术中的数学 | 作为建筑、美学、地图、镜头、空间谜题和岛屿建设规则 |
| 文明历史型 | 《数学的故事》《数学简史》《数学星球：人类文明与数学（万物皆数学）》《数学世界的探奇之旅》 | 说明数学如何从计数、度量、建筑、贸易、天文、战争、艺术中长出来 | 作为文明进阶、岛屿技术树、不同区域文化数学规则 |
| 高阶思想型 | 《爱与数学》《数学思维》 | 进入现代数学的结构、关系、抽象、对称、范畴、统一性 | 不建议直接给小学生做显性内容，适合作为后期世界规则和设计者理论底座 |

## 对《我的数学岛》的取舍建议

| 优先级 | 应优先吸收的书种 | 理由 |
| --- | --- | --- |
| P0 | 基础体系型、艺术建筑型、文明历史型 | 这三类最容易转化成“采集、合成、建造、地图、文明进阶”的可玩规则 |
| P1 | 趣味启蒙型、现实决策型 | 适合做任务、反馈、经营和风险系统，增强游戏性 |
| P2 | 高阶思想型 | 先作为设计者底层理论，不要直接塞给小学生 |

## 推荐拆分后的使用方式

1. **游戏规则库**：以《极简数学》为主，承接小学数学知识点。
2. **真实世界来源库**：以《数学星球》《数学简史》《数学的故事》为主，解释数学为什么出现。
3. **建造与空间库**：以《感官的盛宴》为主，支撑岛屿建筑、视角、地图、比例、美学。
4. **风险与反馈库**：以《救命的数学》《魔鬼数学》为主，设计错误决策带来的世界后果。
5. **兴趣任务库**：以《12堂魔力数学课》《用数学魔法改变人生》为主，设计低门槛、强反馈的小任务。
6. **设计者理论库**：以《爱与数学》《数学思维》为主，支撑长期世界规则和系统抽象。

## 一句话结论

这个合集不应该被当成一本连续教材使用，而应该拆成六类素材库：**启蒙、基础、决策、艺术建筑、文明历史、高阶思想**。其中真正适合当前儿童创造型数学游戏优先落地的是：**基础体系型 + 艺术建筑型 + 文明历史型**。
