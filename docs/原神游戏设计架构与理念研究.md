# 《原神》游戏设计架构与理念研究

日期：2026-06-17  
用途：为《我的数学岛》的核心交互、造物台、世界规则、长期成长结构提供参考  
研究方式：公开资料研究 + 产品结构拆解 + 设计推断  

> 说明：本文不声称掌握米哈游内部设计文档。所有事实依据来自公开资料；“设计推断”是基于成品体验、系统关系和公开资料做出的产品分析。

## 0. 核心结论

《原神》的成功不来自某一个单点系统，而来自一个高度耦合的产品架构：

```text
开放世界探索
-> 元素规则
-> 角色队伍
-> 资源与养成
-> 版本更新
-> 角色与世界观内容消费
-> 长期留存与付费
```

它不是纯沙盒，也不是纯剧情 RPG，而是：

> 一个以开放世界为入口、以元素反应为规则核心、以角色为商业与情感载体、以版本制内容更新维持长期生命的服务型开放世界 RPG。

对《我的数学岛》最重要的启发不是“做成原神”，而是：

1. 核心设施必须长期存在，例如原神的合成台、传送点、七天神像。
2. 世界规则必须可复用，例如元素反应既服务战斗，也服务解谜、探索、角色构筑。
3. 玩家要先因为世界需求行动，再理解规则。
4. 角色、资源、地图、任务、成长必须围绕同一套底层规则运转。
5. 不要让学习系统外置成“教学面板”，要让它成为世界机器的一部分。

## 2. 产品定位

公开资料将《原神》描述为开放世界动作角色扮演游戏。其基本形态包括：

- 开放世界探索。
- 动作战斗。
- 元素系统。
- 可切换的四人队伍。
- 角色、武器、圣遗物、天赋等养成。
- 免费游玩 + 祈愿抽取角色/武器。
- 定期版本更新。
- 多平台发行。

从设计上看，《原神》不是“无限创造型沙盒”，而是“内容驱动型开放世界服务游戏”：

| 维度 | 《原神》的选择 |
| --- | --- |
| 世界 | 大型手工开放世界，而非玩家自生成世界 |
| 目标 | 探索、剧情、收集、角色养成、挑战 |
| 核心规则 | 元素附着、元素反应、角色队伍切换 |
| 长期留存 | 新地区、新角色、新活动、新剧情、新养成材料 |
| 商业核心 | 角色与武器祈愿、月卡、战令、外观等 |
| 用户关系 | 玩家消费世界内容与角色，不主要生产世界内容 |

## 3. 总体系统架构

可以把《原神》拆成 8 层。

| 层级 | 系统 | 作用 |
| --- | --- | --- |
| 1 | 世界层 | 地图、地貌、区域、传送点、七天神像、资源点 |
| 2 | 行动层 | 跑、跳、攀爬、滑翔、游泳、互动、战斗 |
| 3 | 规则层 | 元素、元素反应、元素共鸣、敌人护盾、环境机制 |
| 4 | 角色层 | 角色、武器、天赋、命座、队伍组合 |
| 5 | 资源层 | 经验、摩拉、素材、树脂、圣遗物、原石、命运 |
| 6 | 任务层 | 魔神任务、传说任务、世界任务、每日委托、活动任务 |
| 7 | 运营层 | 版本更新、限时活动、卡池、深渊/剧诗等周期挑战 |
| 8 | 情感/IP层 | 国家文化、音乐、美术、角色关系、剧情伏笔、社区传播 |

其核心结构不是线性的，而是循环的：

```text
看见远处目标
-> 前往探索
-> 遇到敌人/谜题/资源
-> 用角色与元素解决
-> 获得材料、宝箱、剧情或原石
-> 养成角色或抽取角色
-> 队伍能力增强
-> 探索更难区域和挑战
-> 等待下一版本内容
```

## 4. 玩家体验循环

### 4.1 短循环：1-5 分钟

```text
看到地标/宝箱/怪物/采集物
-> 移动过去
-> 互动、解谜或战斗
-> 获得即时奖励
-> 发现下一个目标
```

设计价值：

- 玩家几乎永远有下一个可见目标。
- 路上会自然产生偏航：采集、宝箱、怪物、支线。
- 奖励不一定很大，但足够维持探索惯性。

### 4.2 中循环：20-60 分钟

```text
接任务或设定养成目标
-> 探索区域/刷副本/打 Boss
-> 消耗树脂或时间
-> 获得角色养成材料
-> 提升角色
-> 推进剧情或挑战
```

设计价值：

- 任务给方向。
- 材料给重复理由。
- 角色养成给长期目标。

### 4.3 长循环：版本周期

```text
版本前瞻
-> 新角色/新地图/新活动预期
-> 抽卡或养成准备
-> 版本上线集中体验
-> 活动与日常维持活跃
-> 等待下一版本
```

设计价值：

- 运营节奏把玩家期待转化为回流。
- 角色、剧情和地图共同构成版本卖点。
- 限时活动制造短期回访，永久地图提供长期资产。

## 5. 开放世界设计

### 5.1 世界不是背景，而是内容容器

《原神》的地图承载多类内容：

- 主线剧情。
- 世界任务。
- 采集材料。
- 宝箱。
- 解谜。
- 怪物据点。
- 副本入口。
- 传送点。
- 地方文化与美术主题。

这意味着玩家不是在一张地图上“找玩法”，而是地图本身被设计成玩法密度场。

### 5.2 地标牵引

常见动线：

```text
远处看见巨大建筑/山体/光柱/传送点
-> 玩家主动前往
-> 路上被中小目标打断
-> 最终抵达大目标
-> 解锁传送或任务
```

设计原则：

- 远景负责“想去”。
- 中景负责“路上有事”。
- 近景负责“可以互动”。

### 5.3 区域是产品单元

每个国家/大区域通常不是简单换皮，而是组合了：

```text
地貌主题
+ 文化原型
+ 元素主题
+ 角色阵容
+ 地方音乐
+ 新怪物
+ 新机制
+ 主线章节
+ 区域材料
+ 版本活动
```

这使“新地区”成为一个完整产品包，而不是一张新地图。

## 6. 元素系统

### 6.1 元素是底层规则语言

《原神》的七元素并不是只给角色分类，而是一套连接多个系统的规则语言：

| 系统 | 元素的作用 |
| --- | --- |
| 战斗 | 元素附着、反应、增伤、控制、护盾破除 |
| 角色 | 角色身份、技能、队伍定位 |
| 探索 | 点燃、冻结、导电、扩散、激活机关等 |
| 解谜 | 元素方碑、元素顺序、环境互动 |
| 地区主题 | 国家理念、神明、区域审美 |
| 商业 | 新元素/新反应/新角色带来构筑需求 |

### 6.2 元素反应的设计价值

元素反应的设计强点在于：

- 单个元素很容易理解。
- 两个元素组合后产生新效果。
- 多角色队伍让玩家主动设计组合。
- 同一规则能迁移到战斗、探索和解谜。

抽象成结构：

```text
简单标签
-> 可组合规则
-> 反馈明显
-> 队伍构筑
-> 内容扩展
```

这对《我的数学岛》的启发极大：数学规则也应该像元素一样，成为“世界反应系统”。

例如：

```text
水果 + 水果 -> 水果订单成立
种子 x 6 -> 农田蓝图
6 份食物 / 3 人 -> 公平饭桌
同面积 + 不同边界 -> 不同建房成本
```

## 7. 角色与队伍系统

### 7.1 角色是多重载体

《原神》的角色同时承担：

| 角色维度 | 作用 |
| --- | --- |
| 战斗单位 | 技能、元素、武器、数值、队伍定位 |
| 养成目标 | 等级、天赋、武器、圣遗物、命座 |
| 情感对象 | 人设、剧情、语音、生日、关系 |
| 商业载体 | 祈愿卡池、复刻、武器池、外观 |
| 内容入口 | 传说任务、活动剧情、区域故事 |

角色不是单纯的“皮肤”，而是把玩法、经济、叙事和商业合在一起。

### 7.2 四人队伍与快速切换

四人队伍带来两个关键效果：

1. 玩家不是只练一个角色，而是构筑组合。
2. 元素反应需要不同角色配合，推动玩家理解系统。

队伍设计的本质：

```text
角色 A 提供元素/功能
角色 B 触发反应/输出
角色 C 提供保护/治疗
角色 D 提供增益/补位
```

它把“抽到角色”转化为“我可以设计新的玩法组合”。

## 8. 合成台与世界基础设施

### 8.1 合成台为什么成立

合成台是《原神》中非常重要的基础设施。公开资料显示，合成台用于炼金，分布在提瓦特各地，并在地图上有图标。

它的设计价值不是“做材料转换菜单”，而是：

| 设计点 | 价值 |
| --- | --- |
| 世界内可见设施 | 玩家知道这是世界的一部分，不是外置功能面板 |
| 多地点重复出现 | 形成长期心智 |
| 多类转化 | 材料升级、药剂、转换等都能统一到一个设施 |
| 与养成强绑定 | 角色突破、天赋、武器养成都需要材料转化 |
| 低操作成本 | 不抢主玩法，但高频有用 |

### 8.2 合成台对《我的数学岛》的关键启发

我们的“造物台”应该学习的是这个结构：

```text
世界内长期设施
-> 承载多类规则
-> 连接资源、配方、建筑、交易、自动化
-> 每次学会新数学规则，造物台多一个可用功能
```

不应该变成：

```text
教学面板
-> 知识点列表
-> 做题入口
-> 一次性关卡
```

因此，《我的数学岛》的核心设施应是：

```text
造物台
  - 材料识别槽
  - 农田蓝图
  - 饭桌分配
  - 建筑地基
  - 商人货箱
  - 后续厨房/自动机/地图仪
```

## 9. 养成与资源经济

### 9.1 多层养成

《原神》的角色成长不是单一经验条，而是多层资源网络：

| 养成层 | 资源/系统 |
| --- | --- |
| 角色等级 | 经验书、摩拉、突破材料 |
| 武器 | 武器等级、突破材料、精炼 |
| 天赋 | 天赋书、周本材料、摩拉 |
| 圣遗物 | 套装、主词条、副词条、强化 |
| 命座 | 重复角色转化为能力增强 |
| 队伍 | 元素共鸣、反应、循环、站场/后台分工 |

这套结构让玩家长期拥有多个目标：

- 抽角色。
- 养角色。
- 配队伍。
- 刷圣遗物。
- 打挑战验证强度。

### 9.2 树脂的作用

原粹树脂是典型的体力/收益控制系统。公开资料显示，树脂用于领取地脉、副本、Boss 等挑战奖励，并会随时间恢复。

设计作用：

- 控制高价值材料产出速度。
- 让玩家形成日常回访。
- 把“刷材料”从无限肝变成周期管理。
- 为付费恢复与资源规划提供空间。

对儿童教育产品的启发要谨慎：不要照搬体力付费，但可以学习“节奏控制”：

```text
每天世界有自然变化
-> 作物成熟
-> 村民产生新需求
-> 工坊有新订单
```

不要设计成：

```text
学习次数被体力卡住
-> 想继续学必须付费
```

## 10. 商业化结构

《原神》的商业化以角色和武器祈愿为核心。公开资料中，祈愿是其 gacha 系统，包含常驻祈愿与限时活动祈愿。

设计逻辑：

```text
新角色发布
-> 角色有剧情、人设、技能、元素、队伍价值
-> 玩家产生情感与玩法双重需求
-> 通过祈愿获取
-> 再投入资源养成
-> 进入队伍与挑战循环
```

强点：

- 角色同时驱动剧情、玩法和收入。
- 限时卡池制造版本节奏。
- 复刻让老角色重新进入商业周期。

风险：

- 付费压力和未成年人保护问题。
- 角色强度焦虑。
- 抽卡不确定性可能压过游戏本身。

对《我的数学岛》的结论：

> 不应复制抽卡商业化。可以学习“角色/工具作为情感与玩法载体”，但儿童学习产品不应把核心学习能力放进随机付费。

## 11. 任务与叙事结构

### 11.1 任务类型分层

| 类型 | 作用 |
| --- | --- |
| 主线任务 | 推动世界观和国家章节 |
| 角色任务 | 塑造角色，增强抽取/养成动机 |
| 世界任务 | 引导区域探索，解释地方机制 |
| 每日委托 | 维持轻量日活 |
| 活动任务 | 配合版本运营，提供限时体验 |

### 11.2 世界观作为内容组织器

七国、七元素、七神的结构使内容天然可扩展：

```text
一个国家
-> 一个元素主题
-> 一套文化意象
-> 一组角色
-> 一批怪物与机关
-> 一段主线
-> 多个版本更新
```

这不是简单的章节列表，而是稳定的内容生产框架。

对《我的数学岛》的启发：

```text
一个数学岛区域
-> 一个核心数学规则
-> 一套世界问题
-> 一批工具/建筑/角色
-> 一段创造目标
-> 多个可迁移场景
```

## 12. 版本运营结构

《原神》采用服务型游戏模式：定期推出版本、新角色、新活动、新剧情、新区域或新系统。公开媒体资料也长期记录其约六周左右的版本前瞻与更新节奏。

版本结构通常包含：

- 新角色或复刻角色。
- 新武器。
- 新活动。
- 新剧情。
- 新地图或区域扩展。
- 新敌人、新 Boss、新材料。
- 系统优化。

设计价值：

- 保持讨论热度。
- 给玩家储备资源的理由。
- 让内容消费有节奏。
- 让角色商业化和世界更新绑定。

## 13. 美术、音乐与文化建构

《原神》的区域吸引力很大程度来自“国家感”：

| 维度 | 表现 |
| --- | --- |
| 地貌 | 平原、山地、港口、沙漠、雨林、水下、火山等 |
| 建筑 | 不同地区有明显建筑语言 |
| 音乐 | 地区主题音乐增强记忆 |
| 角色 | 服装、命名、语言风格、阵营 |
| 材料 | 地方特产绑定区域 |
| 任务 | 地区问题和地方势力推动剧情 |

真正值得学习的是“区域整体包装”，不是表层二次元风格。

## 14. 设计理念抽象

### 14.1 低门槛，高深度

玩家一开始只需要：

```text
移动
-> 看见目标
-> 打怪/解谜
-> 拿奖励
```

深度来自：

```text
元素反应
-> 队伍构筑
-> 角色养成
-> 圣遗物词条
-> 版本环境变化
```

### 14.2 规则比说明更重要

元素反应不是靠长篇教学成立，而是靠可见反馈：

- 火烧草。
- 冰冻水面。
- 雷水导电。
- 扩散扩大元素影响。
- 护盾被对应元素破除。

这说明教育游戏不能依赖“说明书”，必须依赖“世界反馈”。

### 14.3 角色是内容资产，不只是单位

角色要同时承担：

```text
玩法能力
+ 情感连接
+ 剧情入口
+ 养成目标
+ 社区传播
+ 商业价值
```

### 14.4 地图是欲望管理系统

好的开放世界不是让玩家自由迷路，而是不断提供：

- 远处想去的地方。
- 路上顺手做的事。
- 到达后可解锁的能力。
- 完成后可回看的进度。

### 14.5 运营是产品结构的一部分

《原神》不是“做完一个游戏然后卖出去”，而是持续生产：

```text
地图
+ 角色
+ 剧情
+ 活动
+ 音乐
+ 社区话题
+ 商业节点
```

## 15. 可迁移到《我的数学岛》的设计原则

### 15.1 造物台必须成为长期核心设施

原神合成台的启发：

```text
不是菜单
而是世界里的基础设施
不是一次性教学点
而是长期材料转化中心
```

《我的数学岛》应采用：

```text
造物台
-> 材料识别
-> 数量判断
-> 阵列蓝图
-> 公平分配
-> 地基测量
-> 交易货箱
-> 自动机器
```

### 15.2 数学规则应像元素反应

对应关系：

| 原神 | 我的数学岛 |
| --- | --- |
| 火、水、雷、冰等元素 | 数量、分类、阵列、平均分、面积、坐标 |
| 元素反应 | 数学规则组合后的世界结果 |
| 队伍构筑 | 工具/建筑/村民能力组合 |
| 元素谜题 | 数学世界谜题 |
| 元素护盾 | 世界瓶颈 |

示例：

```text
同类 + 同类 -> 可合并
6 个种子 + 阵列 -> 农田蓝图
6 份食物 + 3 个村民 -> 公平饭桌
面积相同 + 周长不同 -> 建筑成本不同
坐标 + 路线 -> 自动运输
```

### 15.3 区域应按“数学能力”而不是教材章节组织

不要做：

```text
一年级上册
-> 加减法
-> 乘法
-> 除法
```

应该做：

```text
农田区：数量、阵列、面积
村庄区：平均分、余数、公平
工地区：长度、周长、面积
市场区：价格、找零、比例
地图塔：坐标、方向、路线
机器岛：变量、方程、自动化
```

### 15.4 角色可以是认知伙伴，但不能抽卡化

可借鉴：

- 每个伙伴代表一种能力。
- 伙伴有性格和故事。
- 伙伴帮助玩家理解世界问题。

不建议：

- 抽卡获取学习能力。
- 付费决定学习进度。
- 用稀有度制造学习焦虑。

### 15.5 版本运营可以借鉴，但节奏应服务学习

可以做：

- 每月一个新岛屿任务。
- 每周一个创造挑战。
- 节日主题建筑。
- 玩家作品展示。

不要做：

- 限时错过核心知识。
- 用体力限制孩子继续探索。
- 把学习收益做成付费加速。

## 16. 不应照搬的部分

| 原神设计 | 为什么不适合照搬到儿童数学产品 |
| --- | --- |
| 抽卡 | 儿童产品中容易带来付费与概率伦理问题 |
| 树脂式体力 | 会把学习动机变成等待或付费 |
| 大量养成材料 | 对小学用户可能过重 |
| 高强度日常 | 容易让学习变成任务压力 |
| 战斗数值膨胀 | 与创造型学习目标不一致 |
| 复杂文本剧情 | 低年级孩子阅读负担大 |

## 17. 对当前《我的数学岛》PRD 的直接建议

### 17.1 核心设施

保留并强化：

```text
造物台
```

降低：

```text
仓库、分类箱、说明书式操作台
```

造物台应该像原神合成台一样成为长期记忆点：

- 第一阶段：识别材料。
- 第二阶段：合成农田蓝图。
- 第三阶段：生成饭桌分配界面。
- 第四阶段：生成地基工具。
- 第五阶段：生成自动机器。

### 17.2 世界规则

把“数学知识点”改写成“世界反应”：

| 数学知识 | 世界反应 |
| --- | --- |
| 分类 | 能一起叫的材料才能一起合成 |
| 加法 | 同类资源可以堆叠和补齐 |
| 乘法 | 重复摆放变成阵列蓝图 |
| 除法 | 分配不均会影响村民状态 |
| 周长 | 边界越长，建材越多 |
| 坐标 | 标错位置，机器人找不到 |

### 17.3 第一日体验重写

推荐第一日主线：

```text
村民饿了
-> 采集种子
-> 回到造物台
-> 造物台提示：材料混在一起，配方不亮
-> 玩家把材料放进识别槽
-> 水果槽、发芽槽、修东西槽亮起
-> 农田蓝图亮起
-> 玩家选择 2x3 农田
-> 收获 6 份食物
-> 造物台生成三碗饭桌
-> 玩家分成 2/2/2
-> 村民吃饱，支付金币
-> 商人订单验证“2 个水果”
-> 买建房材料
-> 建第一栋小屋
```

### 17.4 验证指标

不问孩子：

```text
你学会分类了吗？
```

而问：

```text
为什么苹果和桃子能一起放进水果槽？
为什么木头会被弹回来？
为什么 2x3 和 1x6 都是 6 块田？
为什么多给一个村民，别人会不高兴？
为什么这个房子更费材料？
```

## 18. 总结

《原神》的可学之处不是二次元画风、战斗、抽卡或大地图规模，而是它把所有系统都压在同一套核心结构上：

```text
世界吸引玩家行动
规则解释世界反馈
角色扩展规则组合
资源推动长期成长
版本不断提供新目标
```

《我的数学岛》应该对应为：

```text
世界问题吸引孩子行动
数学规则解释世界反馈
造物台承载规则组合
工具和建筑扩展创造能力
新岛屿不断提供更高阶数学目标
```

最关键的一句话：

> 不要把数学做成题卡，也不要把造物台做成菜单。造物台必须像原神合成台一样，是世界里真实存在、长期有用、不断解锁规则的核心设施。
