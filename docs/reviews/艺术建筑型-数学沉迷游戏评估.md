## 2. 评价标准

以下标准由上面的事实推导，用于评估“让小学生沉迷学习数学”的游戏方案。

| 标准 | 评价问题 | 通过条件 | 失败信号 |
| --- | --- | --- | --- |
| S1 感官先行 | 孩子是否先被视觉、空间、形状、建筑问题吸引？ | 首屏就能看到歪桥、窄门、空地、未完成建筑或奇怪图案。 | 一开始就是文字任务、公式或知识卡。 |
| S2 空间问题明确 | 数学是否解决可见空间问题？ | 宽窄、长短、高低、遮挡、视角、对称、比例会影响结果。 | 数学只是装饰性标签。 |
| S3 可构造 | 孩子是否亲手构造作品？ | 玩家能摆、拖、旋转、镜像、缩放、连接、搭建。 | 玩家只选择正确答案。 |
| S4 可度量 | 游戏是否让长度、面积、角度、比例、体积产生效果？ | 数值和几何关系会改变门、桥、塔、图案和路线。 | 度量只出现在面板或题目里。 |
| S5 可传播和留存 | 作品是否能保存、复用、展示？ | 孩子做出的门、桥、塔、花园、图案能留在世界里。 | 过关后作品消失，只剩分数。 |
| S6 审美反馈 | 数学是否带来美、秩序、节奏和风格？ | 对称、比例、节奏让作品更稳、更好看、更好用。 | 只判断对错，不产生审美差异。 |
| S7 真实空间反馈 | 错误结构是否在世界中显现？ | 门太窄进不去，桥太短过不了，塔不稳会倾斜，图案不连贯。 | 错误只弹提示或扣分。 |
| S8 非公式化 | 是否避免把艺术建筑数学做成公式课？ | 儿童界面使用宽、窄、歪、正、对齐、能过等语言。 | 出现黄金比例、透视公式、成人术语解释。 |
| S9 成本可控 | 能否用低成本原型验证？ | 2D Canvas 的门、桥、塔、图案即可测试核心体验。 | 一开始就依赖复杂 3D、建筑编辑器和大量美术。 |

## 3. 方案评估

评估对象：用艺术建筑型方法设计一个让孩子沉迷学习数学的创造游戏。

| 标准 | 评分 | 评估 | 类型 | 置信度 |
| --- | --- | --- | --- | --- |
| S1 感官先行 | 高 | 小学生容易被门、桥、塔、房子、花园、图案、机甲等可见对象吸引，适合从感官经验进入。 | 推断 | 高 |
| S2 空间问题明确 | 高 | 艺术建筑型天然强调视觉和空间问题，适合把数学做成门太窄、桥太短、塔太歪等问题。 | 推断 | 高 |
| S3 可构造 | 中高 | 方向非常适合构造玩法，但实际是否成立取决于交互是否允许孩子亲手搭建。 | 推断 | 中 |
| S4 可度量 | 高 | 长度、面积、角度、比例、对称、体积都能映射到可见作品效果。 | 推断 | 高 |
| S5 可传播和留存 | 高 | 建筑、图案和空间作品天然适合保存、展示和复用。 | 推断 | 高 |
| S6 审美反馈 | 中高 | 数学能带来秩序和美，但必须避免主观评价过强；应把“好看”和“好用”结合。 | 推断 | 中 |
| S7 真实空间反馈 | 中 | 如果只做文字反馈会失败；必须实现空间碰撞、通行、稳定、遮挡等可见反馈。 | 推断 | 中 |
| S8 非公式化 | 中 | 艺术建筑型容易滑向黄金比例、透视法、建筑史讲解；儿童版本必须克制术语。 | 推断 | 中 |
| S9 成本可控 | 中 | 2D 原型成本可控；若做自由 3D 建造和高质量建筑美术，成本会快速升高。 | 推断 | 中 |

## 4. 反方观点

| 反方观点 | 为什么严重 | 对应事实 |
| --- | --- | --- |
| 艺术建筑方向可能变成美术搭建游戏，而不是数学学习游戏。 | 孩子可能沉迷造漂亮东西，但无法解释宽窄、对称、比例、空间秩序。 | F1、F2、F9 |
| “好看”太主观，难以证明学习效果。 | 如果只靠审美评价，数学理解不可测。 | F8、F11 |
| 透视、比例、模数等内容可能超龄。 | 低年级儿童更适合宽窄、长短、对称、铺格子，不适合复杂透视和建筑理论。 | F3、F4、F8 |
| 建筑玩法容易成本失控。 | 自由建造、3D 空间、复杂美术和物理稳定性都会拖慢验证。 | F5、S9 |
| 公式化风险高。 | 如果把黄金比例、透视公式、对称轴讲成知识卡，会违背材料警告。 | F11-F15 |
| 用艺术案例包装数学可能不可靠。 | 材料提醒不要声称每个艺术选择都有数学意图。 | F15 |

## 6. 可验证的下一步动作

| 动作 | 做法 | 成功标准 | 失败含义 | 对应标准 |
| --- | --- | --- | --- | --- |
| A1 感官吸引测试 | 给 6 名孩子看窄门/宽门、短桥/长桥、歪塔/正塔三组画面，不解释。 | 4/6 能主动指出哪里怪或想修哪里。 | 空间问题不够直观，无法作为入口。 | S1、S2 |
| A2 门宽构造测试 | 做 2D 原型，让孩子拖动门宽，村民尝试进入。 | 4/6 能调到可通过宽度。 | 宽窄反馈不清楚或操作太难。 | S2、S3、S7 |
| A3 桥长测量测试 | 让孩子用格子铺桥，桥太短过不了，刚好或更长能过。 | 4/6 能通过试错铺到对岸。 | 长度和距离没有被孩子理解。 | S3、S4、S7 |
| A4 对称补全测试 | 给半扇门、半座桥或半个图案，让孩子补另一半。 | 3/6 能补出左右相近结构。 | 对称对目标年龄太抽象或反馈不足。 | S4、S6 |
| A5 稳定性反馈测试 | 让孩子搭塔，底太窄会摇，底宽后稳定。 | 3/6 能解释“下面太窄所以不稳”。 | 空间反馈只像动画，不形成数学理解。 | S4、S7 |
| A6 作品留存测试 | 成功后的门、桥、塔保留在小岛，可命名或装饰。 | 3/6 愿意继续修、改、装饰或展示。 | 没有创造留存动力。 | S5、S6 |
| A7 数学解释测试 | 完成后问“为什么这次能过，刚才不能？” | 3/6 能说出“太窄、太短、不一样、下面不稳”等原因。 | 孩子只是乱试，没有理解结构。 | S8 |
| A8 非课堂感测试 | 全程避免比例、透视、公式、对称轴等术语。 | 不超过 1/6 明确说像作业或上课。 | 表达过于教学化。 | S8 |
| A9 成本控制测试 | 只用 2D Canvas 做门、桥、塔三件事。 | 3 天内可做出可测原型。 | 技术路线过重，不适合早期验证。 | S9 |
| A10 Go/No-Go 汇总 | 用 6 份儿童观察报告汇总。 | 达到 A1-A8 中至少 6 项，再扩展建筑系统。 | 未达标时继续做大建筑系统会放大错误。 | 全部 |

## 7. 建议的最小原型

建议第一版不要做复杂建筑世界，只做一个小场景：

```text
第一座门和第一座桥
-> 村民要进屋，但门太窄
-> 孩子拖宽门，村民能进去
-> 河挡住路，桥太短
-> 孩子铺格子，桥接到对岸
-> 半边桥不稳，孩子补齐另一边
-> 门和桥留在世界里，村民入住，营地亮灯
```

该原型对应的艺术建筑型路径是：

```text
感官经验：门窄、桥短、塔歪
-> 视觉/空间问题：过不去、不稳定、不协调
-> 几何抽象：宽度、长度、对称、支撑
-> 构造工具：拖动、铺格、补全、调整
-> 建筑秩序：门能进、桥能走、结构稳定
-> 改变观看方式：孩子开始主动观察空间关系
```

## 8. 暂不建议做的内容

| 内容 | 暂缓原因 |
| --- | --- |
| 复杂透视教学 | 低年级儿童难以直接理解，容易变成术语课。 |
| 黄金比例关卡 | 容易公式化和成人化。 |
| 大型 3D 自由建造 | 成本高，验证慢。 |
| 艺术史人物和案例剧情 | 容易变成知识包装，偏离操作验证。 |
| 复杂建筑模数系统 | 应等孩子先理解宽窄、长短、对称和稳定后再做。 |

## 9. 当前决策

| 决策项 | 建议 |
| --- | --- |
| 是否继续该方向 | 继续，但先做门、桥、塔小切片。 |
| 是否立即替换当前 PRD | 不建议。先用并行原型验证艺术建筑型是否更吸引孩子。 |
| 是否做 3D | 不建议。第一轮用 2D Canvas 足够验证核心。 |
| 最关键指标 | 孩子是否能说出“太窄、太短、不一样、下面不稳”。 |
| 最危险信号 | 孩子说好玩但无法解释任何空间规则。 |
